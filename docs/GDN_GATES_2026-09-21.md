# GDN gate 预计算实验（2026-09-21）

状态：候选否决，运行时代码恢复到 8ac9820；正式性能参考不变。

## 假设与范围

已接受版本的 200K HTTP 时间线中，GatedDeltaNetRegKernel 累计约
33.55 秒。源码 alpha/beta 只依赖 token 和 value head，与每个 warp
持有的状态列无关。候选用独立 kernel 预计算 FP32 float2 gate 表，
扫描阶段直接读取，保持原表达式、q/k 归一化和递归更新顺序。

仅单序列、kd=vd=128、无 checkpoint 的寄存器路径改变；其他路径
保持原样。T×48×8 字节表在 8192-token 分块占 3 MiB，每个线性层
forward 增加一次准备 kernel、一对异步分配/释放。不复用晚期调试
仍读取的 qkv 原始缓冲。候选补丁及新旧二进制均保留在证据目录。

## E2E 结果

构建无警告，第一项测试为真实 EvalScope HTTP 质量题，11/11 通过，
包括 200K。随后正式性能前三档完成 9 条；8K TTFT 从正式参考
5.626012 秒升到 5.665293 秒，新旧三次范围不重叠。在 44K 阶段
停止客户端（143），服务正常退出 0；200K 性能未运行。

随后固定旧、新二进制，依次重放 1K→4K→8K，各档三次、输出 256、
MTP 关闭、单流、相同配置，无 warmup/probe。两组都完成 9/9，
服务退出 0，输入和输出摘要一致。

| 输入 | 旧 TTFT 均值/秒 | 候选均值/秒 | 旧三次范围/秒 | 候选三次范围/秒 |
|---:|---:|---:|---|---|
| 1024 | 0.843038 | 0.835504 | 0.812109–0.903403 | 0.800753–0.902053 |
| 4096 | 2.845887 | 2.875834 | 2.841916–2.853033 | 2.865324–2.886766 |
| 8192 | 5.633660 | 5.664045 | 5.627607–5.637279 | 5.655992–5.669254 |

4K/8K 相邻对照再次出现不重叠的劣化范围，均值分别增加约
1.05%/0.54%；候选不满足保持性能要求。TTFT 包含 HTTP/分词/prefill，
不是纯 kernel 时间。重复运算减少不保证整体受益。

## 决定与证据边界

撤回候选。没有运行数值专项、微测试、bench 或 profile；不能将
回退归因于某一种缓存、寄存器或分配机制，也不宣称预计算方向本身
不可行。本次只能否决这个额外表、准备 kernel 和生命周期的组合。

恢复源码后构建无警告。重新链接产物 SHA 与已验收产物不同，保留
该重建产物并将 build/q4t 恢复为此前验收的精确二进制：
