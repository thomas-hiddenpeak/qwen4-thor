# 索引键无用计算清理（2026-09-20）

目标：在已修复数学语义的版本上做等价简化，保持输出、质量和五档性能。
本轮质量、输出等价性及五档 E2E 已通过；未观察到相对清理前可分辨的新增
性能回退，保留本次复杂度简化，不宣称稳定的微小加速。前置正确性修复见
[精度排障报告](ACCURACY_AUDIT_2026-09-20.md)。

## 改动边界

旧数据流：原始 ik 投影 → D2D 复制出 ik_raw → 对 ik 做 norm/RoPE → 丢弃 ik；
ik_raw 才是持久原始键缓存和压缩键构造的输入。

新数据流：原始 ik 投影 → 持久原始键缓存 → 按完成组池化、norm/RoPE。
查询仍按原来的 centered RMSNorm 与 RoPE 公式计算并保留跨 warp 同步。
没有改变压缩键计算、top-k、attention 归约或状态布局。

- 查询预处理的 block 数从 5T 变为 4T，删除无消费者的单键头处理。
- 每个 full-attention 层少一条 D2D 复制命令，普通主模型有 12 层。
- 删除 T×128×2 字节临时缓冲；8192-token 分块时该算子需求少 2 MiB。
  不把算子预算减少等同于全模型实际峰值内存下降。
- 正常输出应与清理前相同；若变化，保存证据并判定未通过。

正确性修复版用于隔离本次等价简化的成本；旧版原速度目标仍单独保留。
本次 E2E 不代替并发、MTP、多模态或全面质量基准。

## 性能结果与接受边界

TTFT 为三次算术均值，包含接入/分词/prefill，不是纯 prefill 时间。
decode 为总首 token 后输出数除以总 decode 时间。清理前取固定修复版
参考，历史旧版是数学修复前的同输入矩阵，二者不得混为一个基线。
