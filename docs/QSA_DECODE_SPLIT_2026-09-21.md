基线 98206de。

## 执行和数值边界

原 SparseAttentionKernel 对 T=1 仅有两个 CTA，每个 kv-head 一个。
新独立 CUDA 单元在固定 T=1/nq=24/nkv=2/hd=256 时，将 256 列输出
拆成四个 64 列分片，八个 CTA 计算互斥输出。每片重复完整 QK 与
online softmax，只加载自己的 V 列，不做跨 CTA softmax 合并。

逐输出保留原选择顺序、16 位置 chunk、QK/PV MMA 次序、逐 chunk
max/sum/rescale、BF16 P 舍入、最终归一化与 gate 前后 BF16 边界。
这些源码设计约束已由下述专项核对，但不是对所有输入的形式化数学证明。
多 token 调用仍原 kernel。固定形状单 token 在其他调用场景也可能
走新路径，本轮单流文本不替代 MTP、多模态或并发验收。

## 容量与成本

单 CTA 静态 shared 源码声明 43968→31680 字节，PV 累加器每线程
16→4 个 FP32 值；编译与时间线资源实测见下。
CTA 四倍，整个 grid 的 shared 声明总量 87936→253440 字节，
不能将单 CTA 降幅当作全模型峰值下降。
每个 kv-head 的 K/QK 重复四次，V 总列数不变；仅 K+V 逻辑读账
约为旧版 2.5 倍，不代表 DRAM 实际字节或带宽。收益取决于并行度
是否足以抵消重复工作，不能由 CTA 数推导。
