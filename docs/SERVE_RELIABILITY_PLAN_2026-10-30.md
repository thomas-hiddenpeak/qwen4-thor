# Serve 可靠性收敛：冻结范围与验收

2026-10-30 用户授权按整合计划配置目标并推进。父源码 main `fecfc09`，
问题定位参考 `7e3e941` Serve 审计；已核对 32 份原审计文件，其中 4 份
因增量缓存/计时发生变化，8 项问题路径仍在。默认程序 SHA256 `21eb5204`
及 sidecar 的完整身份、实际构建 cache、原运行时清单和本轮父源码摘要
封存在 `.q4t-work/serve-reliability-20261030/baseline/`。
单一发布候选分支 `codex/serve-reliability`；候选独立构建，不覆盖默认程序。

## 范围和阶段

本轮是正确性/可靠性修复，不作吞吐优化或总体性能非劣声明。保留
all-active 批次选择、槽位准入、prefill 分块、MTP、GPU 算子/精度、
缓存状态布局和现有容量。NVFlare/Spark 仅作为任务身份、唯一完成、
失败排空和资源所有权的设计参考，不引入框架依赖或后台发送队列。

1. 响应：请求级 UTF-8 增量拼接，合法字符原样保留，正常结束的非法/
   残缺序列统一替换，流式/非流式一致；usage 仍按 token 计。传播完整
   非流式发送结果，已知发送失败不计成功/不发布缓存。保留旧首目标
   token 就绪指标，首内容发送指标明确流式与非流式口径。
2. 慢写/取消：网络写移出 tokenizer 锁，非阻塞 send＋有界 poll；
   每次完整逻辑写 30 秒绝对截止，兼顾请求取消/deadline，不随部分
   进展续期。取消终态尽力发送共用短预算。调度器仅处理取消退场和
   唤醒，保留正常选批；已借用/提交对象等完成后才能返回和回收。
3. 分词：每次 Encode 缓存各 added token 下一匹配位置；保留最早
   位置、同位置最长及原顺序。普通 NFC/ICU/BPE 语义保持，合作式
   取消丢弃部分 IDs，不降低输入上限；不声称可抢占任意库调用。
4. 生命周期：监听 fd 发布前后停止合同、线程创建回滚、handler/
   scheduler 异常屏障和资源守卫。区分未提交/借用/在途/完成；不能
   仅 catch 后释放栈对象。无法证明可恢复时停止准入、排空并受控退出。
5. 统计：模型锁内快照与基线更新，锁外输出；并发累计区间不冒充
   精确单请求成本。专家策略与容量不变。

阶段分别提交；提交不是验收通过。每阶段 CPU 合同通过后继续下一阶段，
成组完成后统一真实 HTTP。资源守卫须先于异常恢复路径退出生效，
取消已接受不等于 GPU/IO 已完成。保留 all-active 意味着健康请求仍
可能等慢同伴恢复或超时，本轮不承诺完全消除网络对批次推进的影响。

## 验证及预算

实现/必要构建/CPU 直接验证不计 GPU 验收墙钟；统一验收 prepare 时
冻结绝对起止时刻、候选身份和请求清单，完整 HTTP 至部署健康阶段
最多 **4 小时、110 生成 HTTP、23 服务启动、0 独立 GPU 数值夹具**。
健康/故障请求均计数；健康查询和取消 API 另计。无参数扫描/自动扩样。

| 验证组 | 计划生成 HTTP | 范围 |
|---|---:|---|
| 正常质量 | 36 | 父/候选，plain/full/subset，1K/8K/45K，流式/非流式 |
| 慢写与取消 | 18 | 三模式，慢同伴、正常请求、显式取消、deadline、编码取消、恢复 |
| 缓存交付 | 20 | 两 head，私有/公共发送失败不发布、保存/覆盖/恢复及增量 OFF/ON |
| 异常生命周期 | 18 | 六个固定故障场景，各至多三请求，覆盖提交前后及健康恢复/受控退出 |
| 多槽卸载统计 | 8 | timing OFF/ON，各四请求 |
| 默认安装健康 | 6 | 两 head 各种子、公共恢复、私有恢复 |
| 合计 | 106 | 至多 20 次计划启动；余 4 请求/3 启动仅用于具体失败修复后重验 |

CPU：零警告构建；既有 host 必跑入口；真实 tokenizer golden、特殊
标记和混合输入逐 ID 差分；生产 UTF-8/发送/生命周期函数的边界与
故障测试。原提取控制流探针只作父版反例，不能替代修复实现的验证。
修复接受依直接合同和实际 HTTP 质量，不以 CPU 计时宣称推理提速。
Unicode 分块允许改变，完整合法文本/usage 保持；非法尾部按新合同。

原模型/状态数学证据按未变依赖复用，不重复旧完整推理。保存/恢复
的数学与布局不变，但发送失败后的发布行为和取消必须新验。真实
HTTP 记录客户端首内容、E2E、输出/usage、缓存行为及资源/退出状态；
小幅观察按性能决策协议披露，不建立新百分比容差或反复补采。

GPU 验证完整驱动经 `tools/evalscope/gpu_exclusive.py` 共享独占锁；
不在服务之间释放。环境竞争/监控失败为 ENV_ABORT，仅清理自己
的进程。固定 CPU/资源/HTTP 夹具和配置在正式 GPU 阶段前封存。

## 停止、回退和交付

任何非法 JSON、未约定的 token IDs/usage 改变、失败缓存发布、重复
终态、借用对象提前释放、永久等待、槽泄漏、可疑 GPU 状态继续服务
均否决交付。预算到期停止，不靠延长超时或扩大样本通过；具体失败
修复仅重验受影响项并计入剩余额度。未测/证据不足如实记录。

通过后封存候选/父程序、源码/构建清单、证据与回退包；核对默认
身份仍是本轮父版再替换程序和匹配 sidecar。健康失败按已知身份回退，
未知并发更新停止覆盖。完成文档/日志、阶段提交推送，不启动常驻服务。
已授权的本轮交付不再单独确认。

本目标结束后，按真实 agent 输入的缓存 miss、保存/恢复等待和 PLE
等待选择单一后续任务。PLE 提前读取、缓存异步化、网络框架、动态
页池和调度重构均不混入本轮；增量保存剩余 SHA 成本按新基线判断。

## 指标兼容说明

阶段1将`q4t_ttft_seconds`明确为仅流式、首个非空完整UTF-8内容完成
本地发送；无可见内容的正常EOS不产生样本，非流式不混入。历史
target-prefill结束时点保留为`q4t_target_ready_seconds`，不能把新旧
TTFT曲线跳变解释为推理回归。`q4t_response_seconds`覆盖两种响应
的完整本地发送；均不承诺客户端应用已消费。外部evalscope计时不变。
