## 改动与边界

FullAttentionForward 原先在每次调用中把全部逻辑位置从设备回读，同步 stream，
再在 CPU 求最大值。该代码对短上下文同样执行，旧注释对此描述不准确。
主模型已有同源 host positions：RunLayers 现在每次前向求一次精确最大值，
经 DecoderLayerForward 传给 12 个 full-attention 层，消除这些重复回读和同步。

七条入口覆盖普通 prefill、单 token decode、连续 token decode、多序列 decode、
多序列 verify、变长 prefill 和混合批次。packed/ragged 输入扫描所有位置，
不能假设最后一个位置最大。采用逻辑位置，不采用 MRoPE 坐标或 delta。
不引入持久范围缓存；同一数组用于 H2D 上传及最大值计算。

底层新增的可选参数 max_position 默认 -1，保留 device-only 调用的旧回读。
MTP draft 仍走该回退，因此不宣称所有路径都消除了同步。参数约定为精确
最大值，不能用猜测上界；检查 -1 哨兵及合法范围，数学公式、QSA 候选选择、
归约顺序和缓存布局不变。移除的是位置读取所需的同步，不是所有 host 同步。
