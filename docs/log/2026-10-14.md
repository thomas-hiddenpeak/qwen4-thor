## 45K 档接受率定向分析：内容/输出形态效应，非 45K 路径缺陷（2026-10-14 上午）

- 背景：五档 E2E（2026-10-13）4/5 档 MTP on 达 +50%，唯 45K 档 +43%。
  此前归因"长上下文 draft 质量下降"，但 200K 档 +90%（接受率更高）与该
  归因矛盾。用户要求对 45K 档做定向路径分析。
- 做了什么（定向对照实验，隔离"长度路径"与"提示内容"）：
  1) 复用 2026-10-13 未入档的 200K 接受率对照（.q4t-work/accept-200k-20261013/）：
     200K 38 步 a 均值 2.39（tok/步 3.39），前 ~20 步后稳定 a=3（完全接受）。
  2) 新建 45K 长度对照（.q4t-work/accept-45k-ctrl/）：把 200K E2E 提示
     截断到 ~45025 token（1339 条记录，200K 内容族），同 binary、同
     server 参数、Q4T_MTP_TIMING 跑 128 token。
- 结果判定：
  - 45K 长度 + 200K 内容族：37 步 tok/步 **3.46**，输出为 thinking 块
    （逐条引记录，高度可预测），前 ~20 步后稳定 a=3。
  - 45K 长度 + E2E-45K 内容（1360 条记录）：54 步 tok/步 **2.43**，
    输出为直接流畅综述（无 thinking 块，可预测性低）。
  - 200K 长度 + 200K 内容族：tok/步 3.39（thinking 块）。
  - 每步成本与上下文长度无关（45K-ctrl：draft 15.8 / verify 77.9 /
    extend 9.0，total ~102.8ms，与 4K/200K 一致）。
  - **结论：接受率随"提示内容/输出形态"变化，不随上下文长度变化。**
    同为 45K 长度，不同提示接受率 3.46 vs 2.43。45K 路径（KV/稀疏
    注意力/MoE/draft）工作正常，无长上下文退化。E2E 45K 档 +43% 由该
    特定提示的输出形态（直接综述 vs thinking 块）导致，属客观条件，
    非 runner 缺陷。此前"长上下文 draft 质量下降"归因不成立（200K
    接受率更高已证伪）。
- 边界：未改任何产品代码/行为；仅新增对照提示与运行脚本（.q4t-work/）。
  MTP 仍默认关闭；两候选 env unset。
