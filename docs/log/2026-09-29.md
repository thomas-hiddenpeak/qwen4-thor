报告 `.q4t-work/moe-topn-90-20260929/REPORT.md`。

## 主试验原始路由独立局部性分析

2026-09-29：用户要求对刚导出的原始数据自行分析。新增
`.q4t-work/moe-locality-20260929/analyze_locality.py`（只读 .bin，纯 numpy，
~2s），做区别于既有分布/Top-N 报告的角度：局部性衰减、层间结构、位置漂移、
领域分离、跨层工作集。报告 `REPORT.md`，结果 `results.json`。

数据发现：请求 7/18（精确重复对）0 次 decode——prefill 边界直接 EOS
（finish_reason=stop，completion_tokens=1），decode 统计排除后为 14 唯一请求；
4 组重复路由逐位一致再次确认。

核心数字（decode，14 唯一请求）：
- 池化路由极平坦：熵 0.992、Gini 0.18，Top128 仅 36.5%；逐层 Top128
  56.6%–90.4%（均值 78.2%），无全局热点。
- 时间局部性集中在 ≤8 token：lag-1 top-10 重合 0.107（随机基线 0.047 的
  2.3×），lag-32 回落至基线以下（0.044）。
- 层间 Top-32 Jaccard 均值 0.040，几乎独立 → 跨层共享缓存无结构红利。
- prefill/decode 同层 Top-64 Jaccard 均值 0.116，热点不可跨阶段复用。
- 前16 vs 后16 token Top-32 Jaccard 0.123，127 token 内热点持续漂移。
- 跨层工作集：单 token 203/512 专家，8 token 窗口 476，16 token 后饱和 512。

判断：与既有回放/影子结论方向一致——收益空间在逐层小容量 LRU（32/64 槽）；
大容量与跨层共享预期收益低；预取提前量须 ≤8 token 且逐层独立，请求完成
边界观察器结构上无法利用该局部性。无模型/HTTP 运行，不改验收结论；
样本仍为合成四域 128-token 截断，外推需独立业务材料。
下一步：无；若进入 offload 设计，本报告的工作集/局部性数字可直接引用。
