# 2026-09-29 — 开发日志

## 导出主试验原始路由为可读文本并打包

2026-09-29：新增 `tools/trace/export_raw_routing.py`，把受控采集的
`request-*.bin`（帧格式）导出为可读文本：`routing.csv`（逐 request/forward/
layer 的 top-k 专家 ID，按 [row, top-k] 顺序展开）、每请求 `request-N.tokens.txt`
（实际输入 token）、`requests.json` 与 `manifest.json`。只读输入，不修改采集包，
不新增聚合或缓存/吞吐结论。

原因：用户要把原始数据交给外部 AI 分析，但原始 `.bin` 是二进制帧格式、全量
4.4G（303 个 .bin），AI 无法直接读；主试验（router-study-20260928，20 请求、
3845 万专家 ID）导出为 143M 文本、gzip 后 43M，体积可控且任意 AI 可读。

产物：`.q4t-work/moe-raw-export-20260929/`（含 README 数据说明：列定义、
20 请求领域/种子/长度映射、4 条精确重复样本标记、分析口径提醒）与打包
`.q4t-work/moe-raw-routing-main-study-20260929.tar.gz`（43M，27 条目）。
完整性核对：CSV 110,928 数据行、38,458,560 专家 ID 与 requests.json 一致，
decode 行恰好 10 个 ID。

下一步：无运行时/模型/reference 改动；若需其他 run（shadow/evalscope）的原始
路由，复用同一脚本导出即可。
