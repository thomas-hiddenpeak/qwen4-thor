# 首版收敛计划（一次成组修改，一次统一验收）

用户2026-09-28要求：固定待办，一次检查/修复后统一测试；仅当出现
具体失败时做针对性消融，不逐项重启完整矩阵，不以阶段通过冒充收敛。

## 冻结交付范围

单Thor、指定只读模型、文本greedy、MTP关闭、max_seq=1、
max_prefill=8192、max_len=208896、私有loopback后端及独立数据/控制
代理。支持1K/4K/8K/44K/200K上下文。媒体/MTP、多租户公网接入、
专家offload、数据流改造及吞吐极限不进入本次发布阻塞清单。
认证/TLS由外部可信网关承担；本包不开放公网，不声称提供网关能力。

## 固定工作项及出口

1. **资源边界**：上传绝对时限30秒；正文在读取前按声明长度取得
   全局预算，生成正文总计48MiB，控制正文最多4KiB；文本解析/生成
   在途最多8个；生成含排队默认及最长20分钟，客户端只能缩短。
   计数在所有正常拒绝/取消出口回收。代理不把慢上传
   隐藏在无限时长的磁盘缓冲中，数据/控制连接池保持独立。代理头部
   另有10秒上限，因此经代理的头部+正文最坏预算为40秒。
2. **发布身份**：从当前源码干净构建，固定配置、二进制与模型配置
   摘要；打包、校验、启动、停止、监督重启、升级及回滚可执行。
   旧有数值证据按源码/设备代码身份复用，主机门禁不是全部数值证明。
3. **统一验收**：候选冻结后依次运行主机及资源直接回归、HTTP质量
   11题、21模板、五档各3次性能、取消/错误/回收、代理资源与发布
   生命周期测试。相同检查只执行一次，已有未受影响的证据明确复用。
4. **受控试运行**：同一最终候选连续1800秒混合文本请求，至少60条
   正常生成，包含短请求、8K及200K；记录全文/终态、错误、RSS、
   控制延迟和恢复。独立空闲请求TTFT预算1K 2秒、4K 5秒、8K 10秒、
   44K 50秒、200K 240秒；这些是此次受控运行的运行预算，不能替代
   五档性能比较或被称为真实业务P99/SLO。预热后主机RSS增长不超过
   512MiB，实际资源与请求分布全部记录。新发现的失败必须修复并
   重验受影响检查，不能修改阈值使现有结果通过。
5. **交付关闭**：生成各项PASS/FAIL/复用清单，实际安装验收版本，
   演练升级/回滚，更新默认身份、当前STATUS和发布说明，commit/push。
   未完成项不得标收敛；新增非首版问题仅入后续清单。
