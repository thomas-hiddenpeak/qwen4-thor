# 独立控制入口验证

2026-09-27完成本地有界验收。Runner保持b5f38e48，未启用常驻服务。

## 设计

新增两个独立Nginx master/worker配置，各自有pid、日志、临时目录与
128个worker连接名额；不是同一worker内添加第二个listen。数据入口
只代理生成，控制入口只代理取消/健康/指标，其他路由404。二者均
监听loopback，后端也是loopback；没有启用公网监听或身份鉴权。

数据生成预算4，控制中取消8/健康4/指标4仍各自独立。Nginx连接名额
包括客户端和上游连接，不能把128解释为128个并行模型请求。
依据：[Nginx核心配置](https://nginx.org/en/docs/ngx_core_module.html#worker_connections)。

两个模板在tools/deploy/nginx/q4t-{data,control}.conf.in；原单进程
q4t.conf.in保留作兼容验证配置。使用独立控制入口的调用方必须把
取消、健康和指标请求发送到控制端口，不能继续调用数据入口的
同名路径。控制入口应只对授权的管理/业务网关开放。

## 冻结门禁

- 同等128名额的共享进程对照：真实完整模型请求执行时，以不完整
  HTTP头占满数据连接，日志确认worker_connections耗尽；控制健康
  不能成功。恢复连接后仍能取消及恢复生成。
- 双进程三轮同类耗尽：核对master/worker身份不同，控制健康每轮
  五次及显式取消均在2秒以内，实际请求取消409、槽位归还、短输出
  恢复。2秒是本机此次测试上界，不是P99生产SLO。
- 数据入口HUP reload期间44K输出完整；旧worker退出。机制依据
  [Nginx控制文档](https://nginx.org/en/docs/control.html)。
- 数据入口停机时控制继续可用；活动请求失败并回收，重启后恢复。
  控制入口独立重启不打断数据侧44K输出。
- 最后200K完整文本/usage/stop与冻结参考一致。

## 边界

共享机器的CPU、内存、内核网络资源和Runner仍然共享；独立代理
进程不是任意洪泛/主机故障下的可用性证明。控制入口自身的连接池
仍可能耗尽，需要受信任访问边界和独立资源/频率策略。未做TLS、
远程网卡、外部负载均衡或租户鉴权验收，未做五档代理性能。

本轮验证不会自动安装服务、修改系统防火墙或改变默认二进制。
原十分钟混合负载证据属于单进程配置，不能追认为双进程长稳通过。

## 终态结果

共享进程对照真实触发128 worker_connections不足，健康请求被断开
而未收到HTTP响应；释放压力后取消及短输出恢复。双进程三轮各保持
125个客户端socket时触发同类连接耗尽，日志确认资源边界；该数目
不是已成功接纳的完整HTTP请求数，未读取完整头的连接尚不计入路由配额。

每轮5次控制健康均200，三次取消均202且原生成409，槽位与短输出
恢复。15次健康最大0.587毫秒，3次取消受理最大0.270毫秒，均低于
事先固定2秒门槛。这不是资源释放时间或生产延迟分位数；GPU分块
仍在安全边界排空，两个代理进程也仍共享机器资源。

数据HUP reload期间44K全文保持，旧worker退出；数据进程停止时
控制继续可用、原数据请求断开且后端槽位回收，重启后短输出恢复。
控制进程独立停止/重启没有破坏数据侧44K输出。200K输入204800、
输出7、全文711273及stop一致。Runner和全部代理进程退出0。

共8条正常SSE逐条审计文本、usage和结束原因，102文件终态封存。
第一轮因Thor未提供/proc/PID/task/PID/children而工具失败，改用
父进程查询核对worker身份后完成；失败和成功记录均保留，未放宽
资源耗尽、分离身份或控制响应门槛。

证据目录：`.q4t-work/e2e/isolated-control-shared-v2-20260927/`、
`.q4t-work/e2e/isolated-control-v2-20260927/`及原失败目录。
精确二进制、配置和清单在`.q4t-work/isolated-control-control-20260927/`。
审计脚本`tools/verify/isolated_control/seal.py`只在所有写入进程终态后运行。

本轮交付可选的双进程配置，不自动替换旧单端口调用合同。使用说明
见[独立代理部署](../tools/deploy/nginx/ISOLATED.md)。未新增五档性能
结论或双进程长稳结论；商用验收仍需真实业务并发/队列预算、目标
SLO、认证和实际部署网络，不能继续用本地合成流量扩大已证范围。
