# Realtime 临时凭据的本机签发与兑换合同

JS SDK 7.47.0 为临时凭据单独定义了创建请求和响应，包含对话及转录两种会话资源。凭据到期时间用于决定还能否创建会话。签发期间可以多次兑换同一凭据。默认有效期 600 秒，显式期限可选 10 至 7,200 个整秒。请求字段和两种响应独立从 SDK 提取，经固定 TypeScript 编译器与原生校验逐例比对，508 个用例零差异。[类型比对](sdk.json)

本机组件用内核熵生成 256 位随机凭据，按摘要索引。兑换返回所属客户和初始会话配置。墙钟到期或单调时钟经过完整期限后，下一次兑换拒绝，已经交给会话的配置独立持有。每客户最多持有 64 项，进程上限 4,096 项；私有序列化配置另有每客户 16 MiB 和全局 64 MiB 边界。签发拒绝携带私有 MCP 认证字段的公开资源。并发的 80 次同客户签发中 64 次成功、16 次遇限，此时其他客户仍可签发，到期后原客户可继续。[原生用例](native.txt)

7 项原生用例和 7 项公开合同检查通过。初次编译发现重复定义了已有的摘要函数，已改用项目现有实现。本阶段覆盖组件与协议，后续须将签发、兑换、准入和会话初始配置连接到原生 HTTP、WebSocket 与 WebRTC，并完成短期凭据的真实 SDK 验收。[合同检查](public.txt) · [来源审计](inventory.json)
