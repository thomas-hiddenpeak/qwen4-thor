# Live 在主配置与轻量配置上的实际业务

使用当前托管默认包保留的容量、模型资产与音频后端设置，并由正式的 `package.command` 生成两份启动命令。两个阶段各使用自己的 TLS 入口、客户端策略与临时端口，共享本次的私有应用目录。模型令牌与媒体程序摘要均与此前业务短验绑定。

同一严格 GPU 租约内，主配置（MTP 开）与轻量配置（MTP 关）各启动一次。两个客户端均完成实际 SDK WebRTC 创建（HTTP 201）和数据通道开关，各自的 Chat 都返回 42。主配置创建带元数据的 Conversation，轻量配置启动后，原客户端通过 TLS API 取回同一 ID 与元数据，另一客户端收到 404。两个实际配置均确认启用了 Live 录制。主配置用时 38.31 秒，轻量配置 35.41 秒，71 次 NVML 采样成功，模型和入口已清理。[业务记录](business.json) · [原始观察摘要](sources.json)

首次尝试中，驱动对需要凭据的能力端点匿名请求，收到 401；第二次尝试的固定端口仍被占用，未启动模型。已保留原记录，将能力查询改为持有效 Key 的真实 HTTPS 请求，并为每个阶段分配不同临时端口。此次验证包括按配置启动与跨进程状态保留。守护器故障注入、正式托管包及版本回退仍须单独验证。
