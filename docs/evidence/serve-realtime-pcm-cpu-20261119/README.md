# 实际Realtime音频到ASR波形：7项CPU通过

`DecodeRealtimePcm`直接读取已提交音频的两个环形队列片段，处理
PCM16小端有符号样本及G.711 mu-law/A-law，不复制整份输入，不使用
外部编解码进程。验证epoch/sequence、字节/样本/48k时轴extent及
预算后分配最终16k输出，按1024输入样本分批解码并保留重采样相位。
编码值按32768归一化；跨片段的半个PCM16样本也从正确位置读取。
正常结束只排空实际尾部；取消、坏metadata或超限保留调用方原输出。

7项CPU全部通过，0.063699秒、0GPU，host与完整引擎零警告。核对
全部65536个PCM16值的逐位结果；两种G.711分别全部256码与固定
CPython3.12 audioop独立解码结果一致，滤波稳定区域两种相位误差
不超过1e-7。参考仅生成数值夹具，模块路径/版本/SHA256保留；没有
复制参考实现或添加Python生产依赖。所有分片位置给出逐位相同输出，
覆盖不齐字节、精确向下取整尾长、早/中/末取消、坏extent及预算。
实际队列环形跨界、借用期间不释放和准确ack后的排空也通过。

来源963锚点/17负控通过；现有波形重采样、队列和会话治理证据复用，
默认rev326及账本五项身份保持。当前是音频到ASR波形的接线资格，
尚未向模型派发实时会话，不替代ASR质量、协议事件和官方客户端
验收。继续真实转录执行、每轮实际配额、取消/完成与Realtime/Live
后续任务，Serve master保持active。
