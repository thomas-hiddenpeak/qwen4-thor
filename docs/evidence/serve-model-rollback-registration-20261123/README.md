`q4t service version-prepare` 为这类独立副本接收 `--fallback-content-report FILE` 与 `--fallback-upstream-index FILE`，与原有的包、发布和决定文件一起指定。四项凭据须放在可长期读取的固定路径；注册按摘要绑定，重放重新校验。提供历史已验库存与当前已验库存，仅允许这对库存按记录的方向迁移。客户端策略、功能、媒体权限与容量仍各自校验。普通包沿用原有注册合同。

主机安装原来只接受 v18 标签，同时要求最新源码集合。修复后按每个已支持版本的固定清单选择代码，分别读取真实原包与回退包的 168 项来源，并校验系统解释器。此次没有安装或修改主机服务。测试涵盖 v18 至 v27，版本错标、缺少文件、跨版本混合及额外源码均被拒绝。
