# R08/R09 跨 boot 原资源核验 CPU

31项针对性CPU首过，累计6.995秒，0GPU/0宿主重启。
6新增资源核验用例使用明确历史boot记录及实际降权进入的新CPU
内核域；另有8跨boot（新增1重复boot检查点）、8策略、4存储、
3运行（新增1普通启动绕过拒绝）、2封包。不是现场宿主重启验收。

原资源绑定能够补足离线stop更新时钟后丢失的进程出生回执；必须
是原管理员安装连续的新epoch，且实际业务叶为空。缺真实能力、
错安装、已知新boot owner均拒绝；普通启动在GPU租约之前拒绝
未核验的旧outer attempt。检查点只推进实际boot，原ticket/
代次/owner不重选；核验中写入中断、再次boot均保持停止、设备
保护、恢复额度及已扣启动次数。所有自有测试域已清理，默认
身份、宿主设备策略及既有服务未改。

仍须统一后台入口、可选宿主安装/启用/卸载、R07冷准入组合、
统一DRAM压力及适用真实模型业务/可回退交付；不结束R08/R09或
Serve总目标，不把历史数据CPU证明当现场跨boot业务验收。
