# 后端WebSocket会话治理：23项CPU通过

新增独立会话连接类别，后端全局4个、已鉴权客户各1个，普通data、
control和取消槽保持独立。GET精确识别Realtime/Live入口，查询参数
语义留给实际协议；指标记录会话占用/上限/拒绝。CPU核对同一连接
多次取得普通请求槽并分别计RPM/TPM，不能把握手当作整场模型授权。
实际模型每轮准入仍需在下一步会话执行器接线，当前不宣称API可用。

`HttpResponseContext`增加101升级移交和不可逆标记。握手无HTTP正文
或chunk framing；升级后禁止普通写入、错误/异常响应、SSE心跳及
keep-alive复用，即使错误调用者篡改普通状态枚举。已有心跳未回收时
不能升级。真正的WebSocket输出只由单个socket循环负责。

输出邮箱最多4MiB/64帧、单帧1MiB，按字符串实际capacity收费，包括
部分发送的前帧；满时只阻塞模型生产者，按5ms检查任务取消。socket
循环独立处理反向输入、ping/close、撤权及停服，保留逐次发送偏移。
控制帧不插入未完成数据帧；关闭先通知取消，清除未发送帧，已发前缀
最多在1秒关闭宽限内完成，否则异常断开。默认写入15秒、空闲60秒、
整会话1小时，反向流量不能延长写入截止。正常关闭与TCP EOF分开。

23项不同CPU检查通过，共25次执行、0.228920秒、0GPU；最终host和
完整引擎均零警告。含真实socket部分写入、慢读时反向取消、生产者
背压、独立截止、分片/ping、关闭/异常、客户隔离与原HTTP/配额回归。
首次选测清单未去除格式化宏的前导空白，执行前被拒绝，0用例运行；
原记录保留，只修正选测名字后21项通过。复核心跳直写路径后，补齐
守卫并只验3项HTTP检查，19项复用，非行为格式整理有规范化源码核对。
最后发现退出峰值快照早于取消/封闭，可能漏记竞态生产者的最后一帧；
改为先封闭再读统计，固定竞态反例通过，22项已有证据明确复用。

最终来源961锚点/17负控通过，83个后端HTTP路由和142个原生入口路由
保持；这些计数不代表WebSocket模型业务已实现。本组未接ASR/LLM事件
或启动模型，不替代真实音频、官方客户端、每轮实际usage与恢复验收。
尚需调用方计入帧解析/音频/模型工作区等全部RAM，拥有并回收工作线程；
循环的取消通知不会强杀线程或自动重启模型。默认rev326五项身份保持，
CPU进程已退出、未取得GPU租约。继续ASR音频消费与协议接线及全部master。
