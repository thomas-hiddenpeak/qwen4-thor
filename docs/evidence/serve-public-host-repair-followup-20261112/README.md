## 实际运行时修复

CI取消检查不是简单计时噪声。若Copy之后、Write派发之前已取消，
Write正确直接退出，但Entry析构又用无取消Close等待停止的worker。
独立4KiB反例固定复现2.000134秒；Close现接收同一取消条件，失败
时只废弃匹配缓存代次、通知已有控制器清理，不重放未确认操作。
反例修后0.000078秒，原200毫秒边界未放宽；未发布、仅一次copy、
恢复恰两worker代次及旧句柄/独立域保持均有针对性通过。
