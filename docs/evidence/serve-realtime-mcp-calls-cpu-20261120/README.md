# Realtime MCP异步调用所有者：CPU

2026-11-20。20项针对性CPU全部通过，0.314秒，含3项实际本机原生
MCP HTTP组合。两次必要构建均零警告。原18项计划的首构建没有运行
CPU；审查发现尚未发布审批的取消关联缺口后，修复并补2项回归，
首次成组执行20项通过。原计划、原源码和首构建原件均保留。

生成完成后独立管理Propose、审批、Execute和原worker退出后清理。
默认1个worker、上限4个；64条/64MiB私有存储硬上限，非终态预留
两个4MiB结果副本。阻塞worker持续占槽，排队期限不续期，审批等待
最多300秒，原生操作最多30秒。Join在全部worker退出后共用2秒清理
期限；失败可查询且不增殖线程，不自动续模型或重放远端调用。

覆盖审批单次决定、拒绝、ID代际、删除、取消、事件失败、容量、
超时及辅助会话维护错误。取消已落盘但尚未发事件的审批时，精确
保留原审批ID和原生拒绝终态；不创建新审批、不发工具。已知迟到
结果保持，删除历史不会复活；真实完成才发布工具终态。

组件还没有接入公开Realtime会话；本组不代替真实模型工具闭环、
SDK和恢复交付。默认rev396 STOPPED，0模型/GPU。继续配置快照、
模型/历史映射和公开会话接线，总目标仍active。
