# 官方 Agents SDK 配置接口

向原生 TLS 入口发送 `OpenAI-Beta: agents=v1` 后，`/v1/agents` 支持创建与分页，`/v1/agents/{agent_id}` 支持读取、更新和删除。配置与客户端身份绑定。更新以对象版本进行条件写入，省略的设置按 SDK 语义保留，显式 null 的清除或默认行为由字段决定。创建和变更不加载或执行注册的工具。

用 openai-node 7.47.0 创建两项配置，逐页读取并核对七种工具的返回形状。第二个客户列出空集合，无法读取或删除原客户的配置。关停首个模型与入口，在同一私有对象目录启动新的模型和 TLS 入口，使用新密钥映射到原客户身份，完成读取、更新、删除及同户另一条记录的检查。缺少选择头、字段错误和未知模型也分别收到预期错误。

两次启动共 65.119 秒，租约正常结束，62 次 NVML 查询，默认程序、清单和托管状态身份保持一致。CPU 必选 7/7，兼容网关合同及实际 nginx 配置检查 2/2。当前默认 rev440 为 STOPPED。主轻配置资格、可回退交付、标准 Agent 会话及回合业务仍需完成。[可复核身份及原始回执摘要](checks.json)
