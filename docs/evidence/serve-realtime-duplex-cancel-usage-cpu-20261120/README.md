# 取消语音的实际分类计量修复

2026-11-20。Realtime原先只在成功EOF后获取TTS用量，因此取消回答
虽结算了总token，却没有音频/文字明细。新增借用的阶段观察器，在
RunNativeTts完成原计量之后读取实际前后差，包括提前返回和异常。
观察器独立于音频送达与EOF，保留原EOS分类，不改变配额或模型计算。
未知/回退/溢出/不一致计量保持未知，不能从帧数或PCM长度猜token。

10项直接CPU与20来源反例通过：取消/异常析构顺序、未知粘滞、零工作、
正常EOS、无EOF的cancelled/failed明细和原有成功/文字合同。host和
runtime构建零警告，原候选与默认SHA保持，新增GPU为0。当前仅是
开发/CPU通过；原GPU失败保留，尚未颁发资格或替换默认rev376。

接着同一严格租约最多1轻量模型/1WSS/1TLS/2工作/420秒，只验证实际
取消分类与总量、ASR和资源清理。旧成功语音路径按直接CPU和未变
数值/扣费来源复用；之后继续受影响恢复、可回退交付和全部master。
