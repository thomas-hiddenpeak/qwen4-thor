# Realtime输入队列与整数采样时钟：12项CPU通过

固定字节环形缓冲与最多32项提交队列，支持PCM16半样本跨append保留，
完整样本才能commit。以48k整数tick表示会话时间，8k/16k/24k/48k
投影保留余数且不做可能溢出的乘法；只是时间映射，真实波形重采样
仍需接线与验证。协议允许的格式另由session适配器判断。

容量、任务数、整会话音频时长在写入前检查；失败不改数据、时间或
提交回执。clear只删除未提交尾部，已接受时间不回退。FIFO提交以
内部epoch/sequence回收，错误代际、越序和重复完成均拒绝。取消
禁止新输入、删除未提交尾部，但保留工作线程仍可能借用的已提交
PCM，等明确确认后释放；正常结束必须先处理完整尾部，不能假造完成。

12项CPU全部通过，0.0077秒、0GPU，本机host零警告；953来源锚点与
17负控通过。包含多种分块的同一字节流、分数时钟、uint64边界、
真实缓冲回绕、被拒提交保留、时长不退款、取消借用、格式切换及
100轮环形队列复用。没有新增线程或外部依赖，默认rev326不变。

还没有HTTP升级路由、实时重采样/ASR或实际客户端资格。下一步继续
原生接入与会话适配、真实模型/工具及恢复交付；ICL编码器原失败与
待决口径保持，不将此基础模块当作整个Realtime或Serve已完成。
