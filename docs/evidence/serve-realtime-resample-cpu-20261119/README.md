# 持续输入实际波形重采样：9项CPU通过

原生`AsrStreamResampler`把8/16/24/48k单声道规范化PCM转成16k ASR
波形。16k逐位直通；其他速率使用97抽头Blackman窗低通、两种分数
相位、各相位DC归一化，FP64累加再输出FP32。固定128样本历史，
实例小于4096字节，无堆队列和新依赖；最多48输入样本前视，保持
原始时间原点。首尾零延拓，最终样本数为累计输入乘16000/输入率
向下取整；不按网络块舍入，也不补额外音频。

调用方持有有界输出，输出满时停止消费，回执返回准确输入/输出数。
全输入的非有限/超范围、预算、输入输出重叠和关闭状态先检查，
错误不改波形或计数。Finish封闭输入后分批排空真实尾部；取消禁止
继续消费/输出，不能被报告为正常Drained。

9项CPU全部通过，0.0637秒、0GPU、最终构建零警告。验证16k逐位
直通、四种速率与多种输入/输出分块逐位一致、0—139样本短尾计数、
非整数时刻脉冲的时间重心/总量、恒定信号、通带与抗混叠、拒绝后
状态保持、背压及取消/排空。冻结门：时间重心0.003样本、脉冲量
2e-4、DC1e-7、1k信号幅度/RMS误差0.001、11k混叠及8→16k镜像
幅度低于0.0001。未用模型语义代替波形验证。

初次构建中测试初始化列表混用int与unsigned，编译拒绝；修正测试
常量并按项目格式化后构建通过。原编译失败保留，之前没有执行测试，
生产数学未改变。已有分离器重采样实现与模型数值合同不改。
