# 在线server VAD CPU验证（2026-11-19）

29项原生CPU检查通过（0.163930秒），另3项实际官方JS/WSS/原生TLS
回归通过（unittest 1.675秒，驱动1.816秒），0GPU。两种构建零警告；
970来源锚点与17负控通过。该组概率与ASR执行器是明确CPU夹具，不能
代替真实Silero/ASR业务。

持续重采样及512样本VAD状态跨消息保存；实际时间采用48k整数ticks，
对外毫秒只作投影。24k PCM/G.711来自同一严格解码器。静音前缀裁剪
不搬动ASR借用，空隙仍计容量并在对应item归还后释放。每次socket
循环最多分析一帧；无新音频的墙钟空闲不添加静音、不伪造结束。

开始/停止/自动提交共享item身份，包含配置的前缀及尾静音；自动控制
事件最多4条/8KiB且15秒截止，先排入committed再派发该ASR作业。
clear和手动commit重建检测周期但绝对样本计数不退；活跃缓冲需要
先clear/commit再更改检测策略，语音识别设置仍在提交时冻结。

可选CPU VAD资产在101之前按3秒准备截止加载，失败只拒绝该处理器，
手动ASR保持可用；固定模型数值和原手动WSS证据显式复用。每会话
256MiB逻辑预留继续有效，非物理内存硬隔离。默认rev326不替换。

连续中文PCM两句与G.711一句、真实增量/终态、逐轮计费和清理。自动
分段尚未业务验收；降噪/延迟/语义检测、对话/Live、Guardian组合与
可回退交付和全部master任务继续。
