# 大字符串长度语法修复

两个CPU用例先复现同一失败：纯长度1..65536进入逐字符regex NFA，
在构造阶段触及节点资源上限；真实隔离worker同样返回resource错误。
未将进程生命周期峰值RSS误解为本次已证明的物理内存耗尽。

大纯长度约束改用二次幂规则及精确区间，保持Unicode标量计数、JSON
转义和min/max，不移除code字段约束。pattern/format组合保留原处理，
本项不宣称任意大正则交集已解决。代码字节上限、语义校验与worker
内存/工作/时间保护均保持；修复不是性能优化接受结论。

修后10项针对性检查及1项新增分支边界通过，合计11项。包括0/1/
65535/65536/65537、多字节/转义、精确与大下限/区间/无上限、30万词
真实隔离worker和公开程序续接。实际引擎零警告构建，默认rev118保持。

后续固定额外1启动/8创建/900秒真实补验；包含原失败累计最多2启动/
9创建/1200秒。旧失败保留，不重复未改CPU全矩阵。业务、恢复资格、
发行及main仍待完成，全部master继续。
