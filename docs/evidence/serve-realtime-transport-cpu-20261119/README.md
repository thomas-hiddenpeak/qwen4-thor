# 原生WebSocket传输基础：16项CPU通过

共享RFC6455握手/帧解析与编码已实现：客户端掩码、最短长度编码、
64位长度、整条分片消息累计上限、跨分片UTF-8、交错ping/pong、
合法关闭、EOF异常和待确认事件背压。数据缓冲为一次有界字节数组，

既有可选系统libcrypto；模拟依赖失效只拒绝握手，帧处理继续可用。
未增加外部进程或运行时库。共享旧源码先原子脱离，保留旧包身份。
