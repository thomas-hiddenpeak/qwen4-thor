# 原生自定义音色前端计算验证

实现24kHz、FFT1024/hop256、128 Slaney mel、反射384及原幅值/log
方程，原生中间值使用FP64，输出FP32。无需Python/librosa运行依赖。
14个独立CPU合同已覆盖：首次14执行11通过3失败；原因诊断并修改
计算精度后，只重验6矩阵和2个受影响合同，8通过，其余6边界复用。
合计22执行/0.227秒、最新构建2.972秒零警告，919来源/13负控。

原先针对官方CPU FP32实现的log-mel绝对误差1e-4门有3例失败，
原失败保留。逐阶段对照确认滤波器完全相同，低能量FFT舍入被log
放大。诊断工具首次因8.4MB自动表导致栈溢出（0样本）保留，改为
与生产一致的静态表后完成；语法预检错误也保留，均非模型运行。

新增独立高精度参考仍执行固定官方Qwen方程，只把CPU计算/显式
mel类型转成float64；滤波器保持原float32值。六份全矩阵最终FP32
与原生结果相同，仍守1e-4方程门。与原官方FP32最大差0.00436306，
全部值舍入BF16后≤1 ULP。这个量尺反映官方BF16加载下的输入接近
程度，**不说明原生网络已改成BF16，更不能代替FP32网络或真实业务
验收**。完整2048维声纹、实际Base条件合成、注册和恢复继续。

公开原始官方FP32和高精度夹具、原函数/许可、生成器、首次失败、
逐阶段诊断和全部计划/结果。0GPU/模型，默认rev316五份身份不变。
