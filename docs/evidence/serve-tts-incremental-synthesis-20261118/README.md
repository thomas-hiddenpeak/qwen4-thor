# TTS生产资产上传与生成中分块PCM

固定短验21.368秒通过；英文40帧分16/16/8、中文39帧分16/16/7，
首块均在自然EOS之前输出。全部codes与原完整合成相同；完整
PCM经独立无提示ASR，两句原文均匹配。

- 复用生产双资产读取器和无trace图；真实BF16到F32分块上传，
  最大2MiB源+4MiB展开，上传前取消不会发布就绪绑定。
- 未确认PCM时不能推进或覆盖，确认一次后继续；编码器的25帧
  左上下文裁切及每帧1920样本保持已验合同。
- 16帧真实待输出时取消后不能继续、不能伪成功；2帧预算耗尽
  显式失败，不冒充自然EOS。没有新增全模型正确性/性能矩阵。
- 1 talker/1 codec/1 ASR、0主LLM/HTTP；10项显式设备分配全部
  释放，2资产worker回收，租约正常释放。默认rev306保持停止
  且五项受保护身份未变。

必要构建首次仅资格驱动的cudaMalloc指针转换失败，修复后零
警告；原日志保留。897来源锚点/12负控通过。实际产物约4.72MB，
固定16MiB产物和512MiB余量，未下载或更改任何模型。

Chat输出与持久音频历史、服务恢复/主线仍须实现验收。4倍内容
问题及所有master任务保留，不将两句推广为所有声音/风格资格。
