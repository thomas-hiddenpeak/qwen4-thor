# MTP 有限支持入口证据

`b1-summary.json` 是本机 Thor 首次 13 组 host 合同与 6 项实际
加载前拒绝检查，绑定二进制、各日志、返回码与精确错误信息。
`b1-protocol.json` 保存运行前命令/源码；`b1-build-identity.json`
保存新构建身份；`b1-pretest-hold.json` 记录追加暂停时已无进程。

原件位于研究工作区 `.q4t-work/mtp-release-20261008/b1-local/`。
本组不含模型加载、HTTP、数值/质量/性能接受；正常 HTTP 留给
B 最终组。13+6 范围和命令事前固定，独立拆组安排测试后补记，
不能用摘要隐藏这个顺序差异，详见[转正计划](../../MTP_RELEASE_PLAN_2026-10-08.md)。

B2a的 `b2a-frozen-before-first-test.json`、`b2a-summary.json`、三份
原始日志与 `b2a-review.json` 保存新增取消工具27项、既有身份8项、
模式18项的首次53/53结果及运行前源码身份。独立静态审查问题在
首次测试前修正；未执行9请求HTTP，未加载模型/GPU。它仅证明工具
合同可用，不能替代真实取消恢复、token ID或内部状态的数值验收。
