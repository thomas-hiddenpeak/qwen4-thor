# 原生 Live 媒体会话创建与真实资料查询

固定 JS SDK 7.47.0 使用原生 TLS 的 `POST /v1/live/sessions` 提交真实 Opus SDP，HTTP 返回 200。独立 GStreamer 对端完成回环 ICE、DTLS、SRTP 和 SCTP。HTTP 已结束时，同一客户端再次创建会话收到 429。无效 SDP 收到 400。数据通道尝试执行未授权的静音命令得到关联错误，后续音轨仍可输入问题。

对端播放既有 24 kHz 录音，模型转录为“请查询当前项目版本号。”，并委派客户端查询。客户端读取本次冻结的项目 STATUS 并把版本回填到同一会话；输出转录为 rev426，接收端在观察窗口内解码 22,048 个样本，峰值 14,011。公开数据通道中音频 base64 事件数为零。收到同一 ID 的关闭事件后，普通 Chat 返回 42。该客户三次模型准入，结算 1,752 tokens；预留 tokens、会话数和协议主机预算均归零。一次启动用时 66.40 秒，64 次 NVML 查询正常，已清理进程、端口和租约。听感留待人工验证。[真实短验记录](http.json)

27 项原生 CPU 检查覆盖启动失败、证书认证前的消息、独立前端筛选、PCM 分帧及原 WebSocket 生命周期。5 项公开协议检查、原生和可选 nginx 两种实际入口、92 个运行时路由与 32 个审计反例通过。独立媒体进程的 Opus、PCMU 与 PCMA 均在关闭 SCTP 后继续双向传音。缺失媒体插件、证书错误、非法绑定与启动超时使用独立进程验证。真实模型业务本轮使用 Opus。[CPU 检查与构建身份](cpu.json)

- 模型进程使用同目录媒体子进程。GStreamer 与 NICE 由媒体子进程加载；验证使用原已核验的系统包解包目录。媒体依赖缺失以本次媒体请求 503 返回。数据通道单条消息当前上限为 65,535 字节，超限关闭数据通道；主音轨独立。
- 同一客户端的实时名额及全局实时名额从请求转交至会话所有者。关闭、网络失败或服务停止时，先结束本会话的模型工作，再回收媒体子进程与名额。
- 本次验证范围为本机真实对端。跨网 ICE/TURN、可信旁路、存储会话 fork、SIP 信令和带媒体进程的可回退发行仍待完成，现行默认版本为 rev426。

可复验驱动为 [SDK/媒体业务](../../../tools/serve_live/media_create_acceptance.py) 和[纯 CPU 对端](../../../tools/serve_live/webrtc_media_acceptance.py)。原始 TLS、SDP 和认证材料保存在本机忽略目录。
