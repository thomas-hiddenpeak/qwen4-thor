# Live 主轻发布输入与实际 HTTP 身份

此前主轻运行验证了 SDK、Chat、会话持久化和 MTP。封包还需要确定引擎实际接受了全部容量设置，并把工作程序身份和内存准入结果固定下来。资格工具现从真实 HTTP 响应重新分类所有受管容量，校验两套能力声明、程序字节、监控与清理回执，再生成封包所需的观察记录。已有业务可按已发布的验收 SHA 读取，原记录继续保留。

最新候选的主配置和轻量配置均完成核验。分配前准入的 required_bytes 分别为 120783008684 和 114234016052，包括已配置的主机余量。两份配置响应与此前 schema 审计的 SHA 匹配。两代引擎的四份原始观察都通过；九个负例覆盖容量裁剪、内存拒绝、工作程序或入口身份、Chat 内容、协议、主轻能力差异、清理与会话状态。新增模型启动为零。下一步将这些记录与旧完整业务证据一起封入托管资格，再验证 Live 候选实际受管启动。
