# 自定义音色：原生2048维声纹组件通过

原生Qwen Base声纹网络已实际运行。76个BF16权重精确展开为FP32，
47个有界步骤、最多5625帧；全部权重和工作区计入统一RAM。
CUDA FP32计算不启用TF32，沿用既有错误分类与同步；未完成、失败
和重复发布均拒绝。生产不增加Python、PyTorch或librosa依赖。

固定最短合法5帧静音、93帧合成chirp、300/292帧原始中英文音频，
1次完整GPU声纹加载、1次CPU官方参考，36项全矩阵/嵌入对照通过，
8边界和16生命周期检查通过；成功阶段4.127秒。8布局与5验收器
CPU合同共0.179秒。官方类从固定源文件原样提取、严格绑定76权重；
网络相同输入与原FP32前端传播影响分别测量，无BF16输出取整遮蔽。

最终2048向量最大相对L2约1.254e-6、最大绝对误差8.584e-6。
官方FP32前端对最终声纹的最大相对影响5.716e-6、绝对1.526e-5，
原生前端与高精度方程输出逐值相同。全部满足预先冻结门，未放宽。
这补齐之前前端差异的实际传播证据；原FP32前端log门失败仍保留。

首轮测试加载器未分块展开大张量，既有1M元素上限拒绝，0样本执行；
改为2MiB源/4MiB目标分块后按原样本和阈值续验。该部分加载失败和
首次缺system_memory链接失败均保留。累计两次GPU进程尝试，一次
完整加载，0TTS合成/主LLM/HTTP；严格租约结束且监控正常，默认保持。

完整3,857,413,744字节Base源经920段有界下载与按序全SHA核对，
只保留24,061,040字节声纹前缀。原慢速下载有界停止记录保留。
48,004,352字节FP32权重是统一RAM驻留，不是CPU容量卸载。
全模型文件尚未保留；真实Base合成、音色持久注册/隔离和业务调用
