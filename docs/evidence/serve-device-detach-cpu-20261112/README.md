# 设备规则显式撤销 CPU 验收

14项针对性CPU首过，累计1.044秒；必要构建9.246秒，
`-Wall -Wextra -Werror`零警告。5项实际内核、3项实际原生IPC、
4项持久管理、2项封包。规则只附着在新建自有CPU测试cgroup，
只限制/dev/zero，不触宿主根GPU规则、NVML、模型或其他业务。

已区分引用删除与规则撤销：保留旧link FD时，明确detach仍使
规则失效，内核报告cgroup_id=0；原FD不再是有效启动授权。
同一pin在detach后未删除的中断可按原身份续办；代码/域/原link
身份必须一致，另一条规则保持。原低层RemovePin语义保留。

管理入口先撤资格并保存原撤销身份，重试不重新取得启动权，
未完成撤销不能重新arm。新原生detach操作单独命名；旧helper
不支持则拒绝，不把仅unlink降格为“已撤规则”。预算保持，
所有自有cgroup和bpffs测试对象清理。默认包/冻结R07候选保持，
没有发行或GPU业务结论。新helper SHA：`00a8a4837bf81b87135416de250023a925e58bed4f9032e55c2c2d69f2577f3f`。

该修复为后续资源绑定、卸载互锁和逐代许可提供撤销能力；这些
组合与全部总计划仍需继续完成。
