# Live 录音波形和时间线

实现 16 位 PCM 立体声 WAV 编排，输入为左声道，输出为右声道，采用协商的采样率。双方重叠时保留两个声道，缺少样本的时段填静音。录制端按通道分块，下载端每个声道最多持有一个 1 MiB 块，每次输出最多 64 KiB，避免将整通电话放入内存。已有单声道语音 WAV 路径复用通用文件头并保留原有空输出检查。

6 项 CPU 检查覆盖 24/16 kHz PCM、8 kHz 双制式 G.711、声道重叠及静音、空录音、大块分段、写入中断、索引损坏、长度验证和既有语音文件头。本轮新增 GPU 启动为零。接下来接入隔离的对象存储、录制开关和经过身份验证的下载路由。
