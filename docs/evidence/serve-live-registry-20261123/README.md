# Live 正式主轻资格与旧业务还原

正式资格将 Live 实际运行的引擎、入口、三个媒体程序和主轻业务与原 rev428 的逐项业务证据绑定。需要升级声明时，显式部署可把旧的 conversation/live 待办转为已验证的实际能力；其他旧字段仍须完整保留，自动回退仍要求双方业务能力相同。初次正向迁移被原比较逻辑拒绝，已保留原记录并修正该规则。

恢复包 v28 使用自己的来源清单。v27 及更早版本继续按各自清单验证。封包会核对实际安装的媒体程序和两份资格；更换或去掉程序、目前的 Chat 结果、旧工具回填或来源证明均被拒绝。两份记录分别为 5,663,732 和 8,371,673 字节，均在原有 8 MiB 上限内。可从两份新资格逐字节还原之前发布的完整业务记录，保留旧的质量失败。
