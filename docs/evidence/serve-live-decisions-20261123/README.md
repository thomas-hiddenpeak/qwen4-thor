# Live Decisions 主连接验收

OpenAI JS 7.47.0 在一条原生 TLS/WSS 连接内读取真实的项目发布记录。显式 decision.create 和语音模型发起的委派均选中 rev426。客户端用后者的 delegation_id 提交播报，收到语音转录 rev426 与 107,520 字节 PCM，随后正常收到 session.closed 及关闭码 1000。用户听感仍待验证。

输入录音复用已经核验的 24 kHz 项目查询，仅将 PCM 送入 ASR。原生 ASR 正确转录“请查询当前项目版本号。”。七个输入转录片段合成一次待执行的分类，结果指向最后一个真实片段。输出分类指向版本播报的实际片段。输入、输出触发器的判真概率分别为 0.9962、0.9796。

四次 Decisions 共使用 1,073 tokens。客户同时只有一个数据请求名额，本次测试策略允许每分钟八次请求。一次 ASR、两轮语音模型和四次分类实际占用七次准入，共结算 2,582 tokens，预留归零。单次模型与入口启动，65.601 秒，63 次 NVML 采样正常。后续独立普通 Chat 答出 42。已核对测试进程、端口与独占 GPU 锁释放，默认发行仍为 rev426。

25 项针对性 CPU 检查覆盖实际 HTTP 执行上下文、身份、用量、断开取消、重复事件、不可变快照、关联委派、转录和单名额调度。八项离线反例覆盖事件归属、遗漏最终输入、错误结果、配额与终态。真实业务覆盖本主连接案例；下一项为会话录制、内容下载、旁路与 fork。
