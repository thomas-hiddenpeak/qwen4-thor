# 固定半块移位候选结果

3项对齐/负控CPU通过；1次分离模型加载、2保存混音移位输入、
1.525秒，0主模型/HTTP。严格NVML租约COMPLETED且释放；
默认rev296及候选a15e28f0未变，必要replay构建零警告。

固定前补1000个8k样本，输出恢复原时间后，按两视图相关匹配
通道/极性/增益再平均。原未移位输出复用，纯净源只评分，HTTP
整数混音使用其实际舍入后的来源。两路输出与原输出相关分别约
0.999996/0.999999，但平均后的SI-SDR都略降（约0.004/0.005dB），
没有达到冻结的每路不下降条件。拒绝这个候选，不接入生产或
追加其HTTP测试，原词形质量缺口继续保留。

参考[Demucs移位平均思路](https://github.com/facebookresearch/demucs/blob/main/demucs/apply.py)，
Meta、MIT；本地独立NumPy诊断实现，不引入生产依赖，也不以其
公开成绩宣称本模型收益。两个声学候选均无信号改善证据，当前
不继续围绕一个词形试参数；推进已有ASR支撑的Chat音频入口，
重叠质量与实际托管资格仍为未完成任务，全部master继续。
