# Realtime音频实际执行接线：针对性CPU验收

日期：2026-11-20。原生语音接入同一个普通Chat请求、客户准入、RPM、
输出预算与取消控制；真实PCM通过连续编码器进入有界类型邮箱，原生
EOF须匹配已收字节、SHA-256和实际样本数，之后才发布音频完成。
不增加第二次RPM、HTTP回环、外部语音服务或Chat音频历史副本。

会话绑定实际音频与generation票据，支持标准事件、retrieve/delete、
播放truncate、取消和后续文字/工具上下文。截断后清除无可靠样本对齐
的转录，迟到片段不复活。音色在实际首块音频后锁定，语速仅在轮次
之间改变；PCM24k和G.711 8k保留实际时钟。结束时按实际容量压缩保留
缓冲，分配失败保持原有有界计费和健康内容。
