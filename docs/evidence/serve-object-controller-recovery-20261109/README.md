# 对象控制器有界自恢复

2026-11-09。非性能故障修复，无本组新增GPU，无默认更改。

## 修复

对象调度线程异常原先会令同一ObjectStore永久失效。新增同一拥有
线程的监护循环、固定容量故障时间窗口和退避；最终错误出口只用
入队前准备的回执，不分配字符串。未确认活动写入保持unknown，
不重放；排队未执行操作返回已知失败。窗口满额拒绝依赖状态请求，
恢复循环不重置worker启动预算，阻塞spawn仍保留唯一槽。

线程创建已确认失败可由后续请求按相同预算重新尝试；正常运行的
调度线程不会因此增加。停止唤醒退避，只有真正所有者释放槽位，
不影响独立grammar域或模型健康。config增加三项控制器计数。
