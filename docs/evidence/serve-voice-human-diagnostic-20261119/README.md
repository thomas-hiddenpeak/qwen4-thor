# 真人单说话人与异声拼接的独立诊断

复用已校验SpeechBrain固定源码c0241278f93ef02cd5191f03caf4e5f8e1292bf6
的tests/samples/ASR三条录音（A两条、B一条），完整PCM不裁剪、不变速，
另构造A1+A2、A1+B1、B1+A1，连接处固定0.4秒静音。源git blob/SHA
与构造脚本入索引；录音/解码PCM保留本机原路径，没有重新生成夹具。

实际原生VAD/ECAPA后直接调用生产BuildVoiceIdentity：三条原录音及
同人拼接通过，两份异声拼接拒绝。A两条独立录音聚合余弦0.727384，
A/B分别0.076198、-0.000257；同人拼接最低窗口对0.715105，异声拼接
分别0.071809、0.075710。当前窗口和跨录音0.65门完全保持。

1 GPU speaker/1 CPU VAD、18向量、原生1.117秒，0主LLM/TTS/
ASR/HTTP。官方CPU从同PCM独立计算18项均对齐，最大relativeL2
2.28795803e-06、最小cosine 0.999999999997。
初轮CPU因驱动未设CUDA_VISIBLE_DEVICES空值，在import torch及加载
权重前拒绝；严格租约的原COMMAND_FAILED和4次正常NVML记录保留。
仅设CPU环境并复用原GPU输出补验，9.277秒、0新增GPU。
自有进程退出、GPU末次空闲、flock释放及默认身份确认。

结论限于这组真人正反例，不能据此声称通用阈值已校准；原ryan合成
录音低相似度及完整注册HTTP失败保持，可能涉及合成音色或核验模型
对合成音的适用性，尚无正常播放听感结论。不会用降低门槛追认成功。
