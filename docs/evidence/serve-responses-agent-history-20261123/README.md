# Responses 具名多代理历史与公开合同

2026-11-23 在 Thor 上通过原生 TLS 和官方 openai-node 7.47.0 验证了两种新输入项。客户端携带 `?beta=true` 和 `OpenAI-Beta: responses_multi_agent=v1`，模型可以读取成对的代理调用和结果。对应的服务端代理调度、子代理输出及事件、整棵树的预算与恢复继续开发。当前默认 rev434 保持 STOPPED。

| 实际操作 | 结果 |
|---|---|
| 对同一份降雨历史预估输入并生成 | 193 token，实际使用 193，回答 37 |
| 获取存储的输入列表 | 原调用 ID、动作、参数、参与代理和结果保留 |
| 另一位客户读取响应 | 404 |
| 省略具名选择或提交动作不匹配的结果 | 分别为 400 |

复验在一次严格 NVML 租约内启动一次模型，完成 6 次 SDK HTTP 请求；业务及清理共 34.55 秒，进程正常退出，端口释放。定向 CPU 验证包括 3 项原生测试、原生与可选 nginx 的 2 项实际进程回环、2 项公开合同测试；来源审计核对 1204 个位置，通过 36 项变异检查。冻结输入与排队恢复使用私有持久化的具名选择；无此字段的旧记录继续使用原语义。

首次业务的 3 次请求保留在记录中。模型在 32 token 预算内对项目构建代码给出拒答，终态 incomplete。独立核对发现相同历史预估为 232、实际为 229，根因是存储临时分配的结果项 ID 进入了工具提示。修复后只投射动作、参与者与结果，并以调用 ID 关联。CPU 用例对相同内容换用不同存储 ID，要求产生完全相同的消息。首次拒答仍作为模型质量记录。

公开 SDK 类型来自固定源码的 5 个根、55 个节点，许可随仓库保留。机器记录附带运行身份、原始回答、HTTP 状态与捕获文件摘要。本机原始文件位于 `.q4t-work/serve-responses-agents-20261123/business-{01,02}`。[机器记录](checks.json)
