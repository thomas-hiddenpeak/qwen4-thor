# 4倍语速相位锁定原型未通过内容检查

固定1024窗/64合成步、4倍分析步256的独立原型，6项CPU/0.301秒
通过；这只能说明长度、音高、覆盖与合成事件边界，不能替代语音。
实际1次ASR加载/原两句/4.828秒，0TTS/主LLM/HTTP，关键词仍错：
英文native speech被识别为A S V，中文会议下午被识别为欢迎从。
原句和完整输出都保留，正常EOS不能代替内容正确，原型不进入生产。

两句全部输入分析权重覆盖最小为1.5，输出无削波，不能再把失败
仅归于整段跳采样；但这些也不证明声学信息完整。ASR输入由
320/312帧与42/41音频token降至80/78帧和各10 token。该事实提示
需要区分声学损失和识别器时间分辨率，目前未证明根因，不能据此
将内容失败改判。下一步先分析已有声学数据，不追加参数试跑。

首次驱动遗漏既有reference-deps路径，在模型加载前失败；原记录
保留，补齐已存在且逐SHA绑定的依赖后才执行唯一ASR加载。
CPU原型使用NumPy1.26.4，参考环境2.5.2，不声称两环境或未来原生
实现已逐值等价。NumPy/Transformers/soxr仅为开发参考，未新增
生产依赖。默认rev316不变，全部master任务继续。

算法依据Barry、Dorran、Coyle的[DAFx-2008论文](https://www.dafx.de/paper-archive/2008/papers/dafx08_19.pdf)
中短时相位传播和峰值相位锁定公式独立实现，未复制外部源码。
