# 单个混音一致性候选 CPU 结果

2份保存混音、1候选、0.012秒CPU、0GPU/HTTP。原组件和HTTP
整数混音均保留干净源，仅用于评分；候选仅用混音及模型输出
拟合全局符号/增益后平均分配残差。

两份输入的第一路SI-SDR仅改善约0.006dB，第二路下降约
0.0007dB，未过“两路都不下降”冻结条件，记REJECTED，
不接入生产、不追加该候选HTTP。原未投影输出经增益拟合后
重建残差本已仅占混音RMS约0.235%，全局混音一致性不是这里
主要失真。两次目录准备错误（漏run层）原样保留，均0候选
执行，正确路径后的两例只执行一次。
