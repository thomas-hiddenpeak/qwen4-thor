# TTS BF16数值漂移定位

原两帧对照FAIL保持，4/64 codes不一致没有改判。固定native
talker hidden后，60个code选择相同，但内部数值仍偏离；首个
两行输入逐算子发现，首层只有少量BF16舍入差异，第五层attention
明显放大。高精度复算35个实际同输入GEMM，全部在FP32累加与
BF16舍入区间内，35个符号错误负控均能拒绝；没有据此宣称完整
预测器正确或声音质量通过。原tuple观察hook失败亦保留。

处理决定：TTS新后端尚未交付，保留固定BF16权重的全部信息和
模型公式/特殊token/采样，提升talker及预测器执行为FP32，关闭
TF32捷径并显式翻倍驻留权重/缓存预算。随后与官方FP32执行严格
对照，继续要求全部贪心codes相同；不降低旧BF16门槛，不把旧
候选追认为通过，不影响已交付主LLM数值合同。之后PCM/业务/
恢复仍须实际验收，总任务继续。
