# R07 持久准入额度与原生管理适配 CPU 接受

2026-11-12，19 项首次通过：6 预算策略、5 实际 root 私有账本、6
实际原生 IPC、2 直接凭据回归。耗时分别 0.231285 / 0.231923 /
0.131799 秒；必要构建 5.501566 秒，零警告，0 GPU。

预算实现 3 次/30 分钟、6 次/日及 30 秒间隔；首次也计费。实际文件
rename/fsync 故障后保留已扣额度，丢回执不重发凭据，重启/重新资格/
停用不清空历史，缺失状态不重建预算，并发 writer 拒绝。

实际 root 管理进程通过私有 seqpacket 调用一次性 C++ 程序；其退出
后内核 pin 仍在，重新接管校验代码/对象后才交接 FD。root 封印凭据
实际通过 SCM_RIGHTS 返回且管道只能读一次；未知字段、无锁、错规则、
普通用户真实启动与超时均有负控。超时只杀死并回收自己的测试子进程，
父级持有的锁未被解开；没有常驻特权守护进程。
