## 不能直接当成熟实现套用的地方

- `PipelineAudioCache::Config`虽声明max_memory_samples与SSD spill字段，
  当前Append只追加vector；上限和SSD路径尚未执行。因此只吸收独立
  消费者思想，q4t实时接入必须实际限制每客户/会话/流水线及全局字节，
  积压时背压或明确拒绝。Thor统一RAM不能把CPU驻留称为容量卸载。
- `WaitForBarrier`是无截止时间的条件等待，StopWorkers有阻塞join。
  排空顺序有参考价值，但不能据此声称有界停止或崩溃自恢复已成熟；
  q4t须复用自身请求deadline、Guardian/设备保护与恢复额度。
- WebSocket handler使用自有topic协议与字符串查找分派reset/end；
  它不是OpenAI Realtime/Live合同，也不替代q4t严格JSON/schema、
  鉴权和跨客户隔离。完整终态与协议映射须独立实现和验证。
- SessionStore的rename不等于掉电持久性；已读Save路径未见文件与
  目录fsync，List也按目录逐文件扫描。q4t事务存储不降级到此实现。
- 源码结构与README中的历史测试描述不能作为q4t质量、吞吐或恢复
  证据；当前也没有对Orator做完整安全/成熟度审计。
