# Live 录音下载的真实业务验收

实际 OpenAI JS 7.47.0 通过原生 TLS/WSS 发起已授权录制。模型听到“请查询当前项目版本号。”，客户端读取本项目资料并回填，模型播报 `rev426`。正常关闭后 `client.live.sessions.downloadRecording` 返回 HTTP 200。关闭前读取和其他具名客户端读取均为 404。

下载为 24 kHz、双声道、16 位 PCM，共 655,107 帧、2,620,472 字节。独立从文件逐样本分离声道，左声道包含原始查询的 69,120 帧，右声道包含播放片段的 69,120 帧和模型实际发出的 53,760 帧。其他位置均为静音。播放期间丢弃的输入、显式静音期间的有声输入均未混入录音。基于真实文件的五个反例均被识别。[精确位置、摘要与完整运行指标](result.json)

一个模型启动、一个入口和一个会话，三个下载请求，三次计费模型工作共结算 1,725 tokens。后续 Chat 回答 42。耗时 67.360 秒，65 次 NVML 查询正常，GPU 租约与该阶段子进程已释放。私有录音留存于本机验收目录。默认发行仍是 rev426。旁路、fork、WebRTC/SIP、主轻配置和可回退发行仍在总计划中。
