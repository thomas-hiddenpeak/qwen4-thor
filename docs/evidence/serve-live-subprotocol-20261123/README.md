# 原生 TLS WebSocket 子协议

2026-11-23。原生网关曾为 Live 选择 `live`，模型却只回显 `realtime`；之前的 SDK 未请求子协议。现有网关、Live、Realtime 和转录共用同一套按路由选择逻辑。

- [真实握手](http.json)使用实际模型及原生 TLS 入口，显式请求应用子协议。Live 返回 101 与 `live`，另两个连接各返回 101 与 `realtime`；Live 启动和关闭确认属于同一会话。后续普通 Chat 回答 42。
- [CPU 与构建](cpu.json)包含 8 项 HTTP、9 项入口进程和 1 项打包来源检查。最初的新测试遗漏测试函数的成功返回，编译器拒绝，修复后通过。严格租约单次模型启动，持续 36.60 秒，36 次 NVML 正常，全部资源释放。默认 rev426 保持原样。
