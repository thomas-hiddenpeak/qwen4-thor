# Responses Beta 在主配置与轻量配置上的业务验收

此前 12 次官方 SDK 调用覆盖了默认 Beta 选择参数的七种操作。发布对照发现，旧引擎与候选的认证能力声明未体现这项行为差异。新声明公开 `responses.beta_query_selector` 的实际值 `beta=true`，使现有迁移规则可以拒绝自动退到缺少该能力的包。16 项主机能力检查和一项直接覆盖升级与回退的 CPU 用例通过。[SDK 请求记录](../serve-responses-beta-selector-20261123/README.md)

同一严格 GPU 租约内，主配置和轻量配置分别运行 38.36 秒、35.84 秒。两套配置均以原有托管参数和媒体程序启动，真实 Beta 请求计数与生成用量相符，均为 99 个输入 token，回答均为 42。原生 TLS 下，轻量配置能按客户端身份取回主配置持久化的回答，另一客户端得到 404。两个实际 WebRTC 数据通道完成建立、关闭，两次普通 Chat 均回答 42。71 次 NVML 查询通过，两个阶段完成清理。

909 项编译来源对照中，此前 SDK 已验的引擎与本次引擎只相差能力声明源文件。两份可执行程序都含有对应的编译协议摘要。准备阶段两次命令错误发生在模型启动前。当前默认部署仍是 rev432。具名多代理选择参数、正式版本注册和同能力回退继续推进。[逐项结果与原始文件摘要](checks.json)
