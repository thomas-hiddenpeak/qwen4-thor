# R09 连续进程树保管 CPU 验证

6 项不同 CPU 用例接受；首次 2/5 通过，发现 Thor 未提供
`/proc/PID/task/TID/children`。原失败与自限 10 秒的 CPU 后代
退出核对保留，修改候选发现后仅补 3 项失败，通过；新增 1 项
退出/空短 stat 解析边界也通过，总累计 1.546 秒、0 GPU。

真实 CPU 子树覆盖正常退出码、setsid 后孤儿接管与回收、超时
保留 custody、活子树禁止关闭、原有子进程拒绝接管。每项另有
不在该外层内的旁路进程，确认未被误伤。

/proc 扫描只找候选；发送信号前复核实际 PPID/start_ticks，再用
pidfd定向发送。最终只认连续原外层的 waitid/ECHILD；缺数据、
超时、复制JSON或换一位观察者都不是整树清理证明。

尚未接原 Guardian/slot 退休或同 boot 外层丢失后的再接管；
不声称这组 CPU 已完成全部 R09。默认 rev64 保持，继续运行
接线、宿主适配、短验交付与全部总任务。
