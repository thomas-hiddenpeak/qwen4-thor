同一引擎a15e28f0、1启动/3ASR请求/46.323秒，严格租约
COMPLETED、自有资源清理，默认rev296不变。三个输入均4秒，
相同VAD和英语设置，IEEE F32 WAV，未重新运行分离模型。

原始单人与仅经过原生8k限带/恢复/峰值归一化的音频都识别
hurt，WER=0；已有真实分离波形识别hurts，WER=1/7。波形
匹配源0，两个原始相关分别0.992109/0.010198，没有按文字

的ASR/8k带宽都没有问题；仍不是发行资格。

下一步仅用两份已保存真实混音做CPU分析，固定一个候选：
先用原混音拟合两路符号/增益，再平均分配重建残差。真实干净
源只用于评分，不能进入候选计算。参考
[混音一致性投影](https://arxiv.org/abs/1811.08521)公式7；
增益拟合是本项目为任意输出幅度增加的适配。两路SI-SDR都
不得下降且仍各比混音改善≥5dB，失败即不推进该候选HTTP。
