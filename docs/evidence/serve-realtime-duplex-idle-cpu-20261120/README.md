不是按壁钟伪造音频长度。CPU两秒音频在五秒超时后仍标明真实两秒，
真实解码后的32000样本和原输入96000字节均核对，私有转写驱动回答。

零收到样本时提交带私有来源的空input_audio；不合成波形，不调用ASR，
不发送转写成功事件，不扣虚构ASR预算。仅执行快照加入“未检测到语音，
邀请用户继续”的提示，公开transcript仍为空；客户端重建该item不能
获得原生空闲来源。实际Chat规划器及严格固定SDK事件均通过CPU。

当前只有组件和本地后端合同证据，不能替代WSS、真实ASR/TTS质量或
完整恢复。新增runtime构建待与直接混合输入成组完成；0GPU，默认
rev376及动态状态保持，全部master继续。
