# 原生冷许可辅助监护：针对性 CPU

16不同用例全部首过，19次调用累计 42.295 秒。原12项首过后，源码复查
补新boot时钟落点：仅重验3项直接策略/写入行为并新增1项实际存储
与历史boot用例；随后3封包通过。原始命令、输出、计时完整保留。

实际自有root许可进程SIGKILL后有界恢复；连续3次失败进入持久
3次/15分钟上限，重复ensure不能重置。监护进程SIGKILL不杀存活
issuer，后继必须等原内核OFD释放才能另派生。原生停止与host卸载
确认辅助进程退出和锁释放；最终进程检查无自有issuer/watch残留。

普通UID业务侧CPU进程保持原PID；核心/外层/设备及防重放账本未被
恢复辅助进程改写。丢辅助账本只撤新启动，不重新bootstrap。故障
写入拒绝派生。跨boot检查点保持原额度并允许新单调时钟继续冷却；
历史boot为夹具，未重启宿主。设备始终unarmed，未打开GPU或设置
宿主根设备规则，不能替代真实冷准入与模型业务验收。

固定现有Linux与项目存储/进程原语，不引入nginx/systemd依赖。
