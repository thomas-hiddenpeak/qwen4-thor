# 保留历史路径的构建空间整理

继续实时会话开发前，本工作区可用空间降至约180MiB。核对本任务
2026-11-04历史观测验证中的14份只读Prometheus/promtool：内容各自
与已有固定SHA256一致、同设备/所有者/权限，无被选程序正在运行。
保留每种程序的一个原锚点，将12个重复inode用同文件系统硬链接
原子替换，逐个再验SHA256并同步目录；全部原路径和内容保留。

实际释放1,801,052,160字节（约1.68GiB），可用空间约1.9GiB。旧inode、
保留锚点与每条替换记录见result；权限保持0500，没有改写二进制。
该历史通知包校验器要求常规文件、所有者/权限及SHA256，不要求
程序单链接；凭据、锁和状态文件未进入范围。后续若要改这些只读
程序，须先复制分离inode，不能原地覆盖共享文件。

默认rev326五项身份不变，无模型或服务启动/停止，无GPU与业务重验。
没有删除研究代码、独有产物或原始验证记录；当前模型目录、reference
和工作分支实现不变。此整理只恢复后续构建空间，不算业务验收。
