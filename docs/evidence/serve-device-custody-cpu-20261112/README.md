# R07 持久设备规则与接管的内核 CPU 验证

2026-11-12。4 项新增、3 项直接回归共 7 项首次全部通过，0.131 秒；
只在自建测试 cgroup 和 root 私有测试 bpffs 目录操作，使用 zero/null
设备。所有自有 pin、cgroup、子进程已清理；0 GPU、默认 rev64 保持。

真实子进程创建过滤器并 pin，父进程在创建者已退出后确认规则仍然
拒绝域外 open，再独立接管；运行方降到 UID/GID 65534 后仍能从
继承的内核 FD 核验身份。撤销 pin 后，剩余 FD 保持约束，最终关闭
才解除。不存在将进程保活或一份 JSON 当成内核规则持续存在的假设。

接管会重新装载期望的不可变规则（不重复 attach），核对内核程序
tag 和原 link/program/cgroup 身份。实际规则不一致、伪造身份、
非 bpffs 或可写目录、重复覆盖、缺 pin、删除另一条规则均拒绝。
另用真实 BPF_LINK_UPDATE 替换规则，旧凭据和接管均失效；其他规则
保持。普通服务无需管理权限；部署创建/接管需要显式宿主权限。

首个构建后补齐测试子进程异常捕获，避免失败夹具继续运行测试主循环，
因此针对性重建后才执行测试；最终构建 2.694 秒、零警告。
未重复与改动无关的其他 CPU/GPU/性能矩阵，548 来源锚点自检通过。
