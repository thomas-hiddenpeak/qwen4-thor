# SRV-11g：显式CA迁移与真实业务恢复限定接受

2026-11-04。生产实现冻结`7d0d8dec`，完成[冻结范围](SERVE_TASK_TRUST_2026-11-04.md)
及本机短验。网关更换CA后，原持久任务可以显式交接信任材料并继续
已知结果；普通Key迁移仍拒绝CA变化。默认C++程序未改，当前CLI

## 交付行为

- 新增`plan-trust`/`apply-trust`，固定旧/新CA摘要、任务revision、
  文件、store与来源。只允许更换CA，client、TLS origin/IP、Key、
  模型/协议/模板、问题与预算必须保持；不能与普通Key计划混用。
- 活跃、终态、UNKNOWN任务只追加迁移事件。已保存工具结果复用，
  未知结果仍需原显式处置；重复应用不增加事件、请求或工具执行。
  元数据迁移不联网；实际resume仍验证TLS、能力及逐轮输出预算。
- 归档及清理正文后的永久键追加信任绑定事件，主体/原合同摘要
  保持，同键不重建任务；Key与CA变更共用原8次归档变更上限。
- CA有界单次读取形成不可变PEM快照，摘要和SSL上下文使用同一
  份字节，后续路径替换不改变已准备连接的信任集。保留CA/主机名
  验证，不使用系统默认信任库或环境Key日志，不自动重试/重定向。
- 兼容表新增已验SRV-11f精确来源，使用10f归档里的真实来源和账本
  证明可迁移。旧task不会自动改写；旧代码也不能继续解释新增信任
  记录。操作前需停止旧应用进程，再按新手册显式交接。

这不证明CA归属、撤销或自动签发。运维需通过独立渠道核对新CA，
私有计划及摘要记录显式选择，不从网络失败自动获取或信任新证书。
