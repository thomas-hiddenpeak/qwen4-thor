# 文本服务合同与测试门禁

2026-09-27：功能合同回归通过，性能无回退验收未通过，保留旧部署。承接decode错误终态及JSON/HTTP输入边界修复，
本节点冻结首版文本greedy参数行为，默认拒绝未验收的媒体处理，并让
测试缺项/跳过不能被误认成通过。没有新增采样或修改模型kernel。

## API合同

校验发生在请求注册、媒体解码和GPU工作之前，未知顶层字段400。
现有请求身份、取消凭据与期限检查保持；模型名如提供必须匹配服务。

| 字段 | 接受范围与含义 |
|---|---|
| prompt / messages | 必须且只能提供一个；prompt非空字符串，messages非空数组 |
| max_tokens | [1,2147483647]整数，实际输出仍受已配置max_len及模型EOS限制 |
| stream | boolean；stream_options只支持boolean include_usage |
| temperature / top_p / n | 仅0 / 1 / 1，或不提供；始终greedy单输出 |
| presence_penalty / frequency_penalty / repetition_penalty | 仅0 / 0 / 1，或不提供 |
| seed | null或绝对值不超过2^53−1的整数；greedy不采样，不参与计算，不据此承诺跨版本逐位一致 |
| stop | 不提供、null或空数组；非空自定义停止条件400，保留模型自身EOS |
| logprobs / top_logprobs | 不提供、null或false / 0；不生成概率输出 |
| logit_bias | 不提供、null或空对象；非空拒绝 |
| response_format | 不提供、null或仅含type=text的对象；JSON约束/结构化输出拒绝 |
| user | 字符串元数据兼容，不参与计算或提供租户隔离 |
| tools | messages的模型原生输入模板支持，array或null；不承诺结构化tool_calls响应，输出仍是content |
| 模板选项 | enable_thinking、preserve_thinking、add_vision_id为boolean；reasoning_effort为low/medium/xhigh，必须使用messages；chat_template_kwargs内同名项按既有模板优先 |
| 未实现参数 | top_k、tool_choice、parallel_tool_calls、max_completion_tokens及其他未知字段400，不能静默丢弃约束 |

文本content parts仍支持。图片/视频字段默认400，明确提示media disabled，
在base64和图像解压之前拒绝。启动`--allow-media`才允许进入原实验路径；
这不是媒体解压预算已完善或视觉质量已验收。该开关属于服务端配置，
请求不能自行开启。模型视觉资源加载行为没有在本节点调整。

兼容变化是有意的：过去被忽略的非零temperature、非空stop、JSON输出
要求、拼错参数等现在失败；evalscope实际发送的temperature=0和seed
继续接受。HTTP外形不等于完整OpenAI能力，未知顶层字段的拒绝策略不
宣称已实现所有嵌套工具schema验证。

## 测试门禁

- 89处缺GPU/模型/fixture的测试分支改为Q4T_SKIP，框架分别统计
  PASS/FAIL/SKIP；异常计FAIL，默认存在SKIP即非零退出。
- 空注册表、零匹配、空/不存在的必跑清单、未知/重复选中项都退出2；
  先校验完整选择，不能先跑一部分再当成功。
- 失败退出码固定为1，260个失败不会因进程退出码截断变成0。
- --allow-skips仅供显式开发探查，required-list模式禁止该开关。
- 新增q4t_host_tests与固定21项清单；发布包装器校验注册集、退出码、
  每一项PASS及零SKIP，记录二进制/清单身份。不能据该主机门禁称整套
  数值或商业发布通过。说明见[tools/release](../tools/release/README.md)。

## 五档性能

单流、MTP关闭，输入1024/4096/8192/45056/204800 token，每档3次，
输出256 token。旧版b5f38e48采用冻结listen-performance参考，新版
202794eb为本轮采集。TTFT是客户端首token延迟，不是纯prefill；decode
按每次255个token间隔的总耗时聚合（等输出时为调和均值）。

| 输入token | 旧TTFT秒 | 新TTFT秒 | 变化 | 旧decode tok/s | 新decode tok/s | 变化 |
|---:|---:|---:|---:|---:|---:|---:|
| 1024 | 0.797 | 0.796 | -0.084% | 18.577 | 18.577 | -0.001% |
| 4096 | 2.627 | 2.637 | +0.365% | 17.885 | 17.883 | -0.013% |
| 8192 | 5.170 | 5.185 | +0.279% | 18.124 | 18.109 | -0.082% |
| 45056 | 30.451 | 30.478 | +0.088% | 17.860 | 17.855 | -0.029% |
| 204800 | 159.311 | 159.404 | +0.058% | 17.109 | 17.104 | -0.027% |

各档decode及除8K外TTFT的历史/本次范围重叠。8K旧TTFT范围
[5.165856,5.174548]秒，新[5.180248,5.189887]秒，不能直接记为
无回退。限定一次旧/新/新/旧ABBA，每服务3次同8K请求，保留首轮
结果，不反复选择有利样本。12条输出全部同参考。

| 8K对照分组 | 旧TTFT秒 | 新TTFT秒 | 旧decode tok/s | 新decode tok/s | decode变化 |
|---|---:|---:|---:|---:|---:|
| 全部各6次 | 5.204848 | 5.214954 | 18.141546 | 18.091281 | -0.277% |
| 每服务首请求，各2次 | 5.270301 | 5.283049 | 18.039242 | 17.998476 | -0.226% |
| 每服务后续请求，各4次 | 5.172122 | 5.180907 | 18.193135 | 18.138043 | -0.303% |

总体范围重叠并不足以接受：按请求顺序区分首请求与后续请求，避免
首请求开销掩盖差异，decode范围分别为旧[18.025429,18.053077]、
新[17.988134,18.008830]；旧[18.169098,18.216138]、
新[18.114049,18.153156]，均不重叠。首请求TTFT也不重叠，
后续TTFT范围重叠。本轮样本不能证明普遍/长期回退，但也不足以
宣称无可检测回退；不追加有利样本、不改容忍阈值、不更新性能参考。

静态对照确认两个二进制的`.nv_fatbin`均为2405808字节，SHA256
`54829212e2702dbf54fff9c5e8d692f3d07df0cf8a332e53d7a4c934a5904184`，
GPU代码包逐字节相同。这缩小了下一步调查范围，但不证明运行时
调度、host开销、分配/缓存布局或环境影响相同，也未定位因果。
下一节点限定为定位该8K版本差异，先检查host路径与构建/布局身份；
本节点不修改kernel或恢复已知错误来追求旧性能。


## 后续边界

首版受控配置是文本、greedy、MTP关闭、单Thor私有后端，正式性能按
max_seq=1和五档评估。媒体实验路径、全局主机/临时磁盘预算、慢上传
总时限、真实业务并发/尾延迟、外部监督恢复与认证/TLS仍需独立交付。
主机前置工具不代替数值合同、HTTP质量、性能及业务运行验收。
