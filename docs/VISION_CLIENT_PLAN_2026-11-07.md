## 输入与输出合同

- Python `chat_client.with_json_schema` / `make_request(json_schema=...)`、
  JS `withJsonSchema` / `makeRequest(..., ..., {jsonSchema})`：显式同一
  schema送给约束后端并展示给模型。共享指令，紧凑JSON；文本字符串、
  媒体parts及真实工具结果后的最终回答均支持。追加到最后一条user消息，
  不修改工具结果、调用方对象或模型输出。字段/枚举应有业务含义描述。
- 已有response_format拒绝覆盖；tools需显式none；不启用缓存组合。
  schema最多64KiB、有效Unicode/有限可互通JSON数值、object根；完整
  支持的schema子集仍由服务preflight校验。语法正确不保证事实正确。

  保留512默认并可配置。JS显式支持任一token字段，拒绝两者同时给出。
  预算正整数且不超过INT32_MAX，实际上下文/资源限额由preflight检查。
  截断不得成为业务成功，不自动加预算、不自动重试、不重复执行工具。
- 旧视觉helper转发共享实现；紧凑JSON改变提示空白，旧视觉证据不直接
