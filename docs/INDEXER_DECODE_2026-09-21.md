## 改动与约束

FullAttentionForward 的短上下文分支中，非空 seq_id 原来使用
IndexerLogitsKernel，每 token 一个 256-thread CTA，循环处理 2048
个候选组。候选固定 T=1/n_iq=4/hd=128/max_blocks=2048，分派到
独立 indexer_decode.cu，grid=(8,1)，每线程处理一个候选组。

保留每分数 h/d 累加次序、FP32 dot/relu/sum/scale、可见性 mask、
seq_id 切片偏移和输出槽位。query 与 compressed key 为只读，logits
沿用原缓冲，无新分配或同步；后续 top-k 不变。seq_id 为空的 BF16
GEMM 路径及长上下文路径不替换，两者数学中间舍入不同。

更多 CTA 可能提高并行度，也可能增加调度及 query 跨 SM 读取成本。
源码没有减少数学运算或解决所有 K 访问跨线程步长问题；局部收益不能
从 CTA 数量推断。必须完成五档性能，含只受编译影响的长上下文。
