# GRRead 成对 BF16 gate+mix 候选

日期：2026-09-21。父版 79dd7a6，固定参考 fcb5925。状态：零警告构建，质量及 HTTP/输出通过，完整 HTTP、相邻复核、逐位与时间线通过，已接受。

## 依据和边界

已验收父版 4K HTTP 时间线中 MixGateKernel 在 prefill 累计
130.558208 ms、97 次调用。当前每线程一个输出 channel，逐分支读取
up 和 normed，FP32 sigmoid、乘加，最后除 hc 并舍入到 BF16。

候选每线程处理相邻两个 channel，使用 BF16 pair 读取和输出，两个
FP32 累加器各自保持分支顺序。hc/hs 仍为运行时 kernel 参数，不改
除法表达式。固定 hc=4/hs=2560 且三指针 4 字节对齐才走成对路径，
其他形状/地址保留原路径。CTA 线程数 256→128，每 CTA 输出元素数
和 grid 数保持；prefill 和普通 decode 均应用，不切掉短序列验证。

不改变 gate 数学、scratch、分配、生命周期或 kernel 数量，也不减少
逻辑读取字节。源码向量访问不等于编译指令或 LPDDR 流量实测改善。
新增分派和代码需要可辨识收益才能保留，不按“复杂度降低”接受。
