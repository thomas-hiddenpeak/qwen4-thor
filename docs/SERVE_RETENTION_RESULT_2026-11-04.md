# SRV-12e 受管代次与私有留存：本机短验限定接受

冻结 `8ab647d9`。新增独立 store/runner 入口，补跨运行目录的准入
预算、已停止记录封存、私有有界读取及显式计划清理。原生产包、
默认 `7619966e/a2f9cb8f`、三份用户 day 计划均不变，未运行长稳。

## 开发与 CPU

新 store 绑定随机身份、UID/权限和目录 inode；后端/网关启动前
分别预占 96/32MiB，容量不足直接拒绝。活跃和未封存代次保留，
只有已核验内容与进程清理的代次能被显式计划删除。中断删除通过
持久意图、原子改名和剩余文件身份核验继续；不扩大到未知记录。

CPU 首组 20 项通过，包含真实子进程、实际轮转、wrapper 死亡后的
parent-death 回收、只读 reconcile，以及真实默认 v4/v2 包入口核对。
之后调整封存前终态记录，移除会过时的 sealed:false 字段；相关单项
及新增失败时先停网关的检查通过。新增环境分类检查复现驱动将 GPU
观测拒绝误标为 FAILED，修正后单项 ENV_ABORT 通过；原失败保留。
最终 22 项不同合同有效通过，未改动的通过项复用，合计执行 24 次。
上述环境拒绝是 CPU 注入检查，不是一次真实 GPU 环境中断。

## 实际闭环

复用 SRV-10d 后端 v4 包 `971dc713…` 和托管网关 v2 包 `3c4c31b5…`，
后端仍 127.0.0.1:18128、TLS 网关仍 127.0.0.1:18448。整个模型/HTTP
阶段使用生产 controller 的同一原 GPU 租约，所有网关先退出再停后端。

| 项目 | 实际结果 |
|---|---|
| 运行代次 | 1 模型、2 个显式网关代次，均无自动重启或请求重放 |
| 目录准入 | 后端 96MiB + 活跃网关 32MiB 预占满 128MiB；额外启动在创建代次/子入口前拒绝 |
| 业务质量 | 6 请求全部成功：普通、严格 JSON、真实资料工具及回填、SSE 1–40 排空、重连 beta |
| 真实资料 | 实际读取 docs/MODEL.md:L1-L24，架构回答与引用正确 |
| 清理与恢复 | 先完整保存第一代网关封存记录，再按显式计划删除；活跃后端保持同一 PID，第二代恢复成功 |
| 资源回收 | grammar 3/3；三个代次均 STOPPED 并封存，最后留存后端与第二代网关 |
| 时间/观测 | 原 GPU 租约 57.806796 秒、55 观察无竞争；全程 68.595250 秒、9 显式控制 |
| 停止 | 10 秒无复起；10 个自有进程身份均退出，GPU 空、原锁可用 |

6 次 HTTP 从请求发送到完整 EOF 的 min/median/max 为
0.332/1.666/4.049 秒，仅记录本批业务时延，不作性能优化或五档非劣结论。
最终两个封存目录的 payload 分别为 183950 字节（后端）和 7780 字节
（第二代网关），seal 文件另计；这不是整盘物理块占用。

原锁保持 dev=66305/inode=3294067。容器空，SOAR 恢复 unit 仍
masked/inactive/dead/MainPID=0；未新增常驻 unit/timer。原件之外只删除
了本批新 store 中一个已经保存副本的网关代次，未管理或清理旧验收目录。

## 证据与边界

[公开证据](evidence/serve-retention-20261104/result.json)封存 199 份原件、
2 个本机 ELF 身份，压缩 285043 字节；包含全部 CPU 来源/结果及原始
环境分类失败、冻结计划、6 份完整 wire、工具结果、三个封存代次的
原样副本、删除计划/结果、私有 tail 身份和收尾记录。离线重新解析、
内容哈希和清理核对通过，0 新模型/HTTP。凭证和私有配置未进入 Git；
归档中的本批合成/项目查询日志不改变生产日志应受私有访问控制的要求。

[操作说明](../tools/serve_retention/README.md)提供 init/run/list、正式停止、
reconcile、tail、计划清理和中断继续入口。没有自动启用或迁移现有服务。
同 UID/管理员是可信控制面；flock 和 SHA 不等于安全隔离或签名。

本项证明受管 namespace 的代次准入和明确删除范围，不证明文件系统
硬 quota、全盘块占用、物理 RAM 上限或长期公平。未知退出仍保留并
拒绝清理；证据不足的失联情况不强行封存。正式日志访问/周期、实际
LAN 与外部通知接入、应用恢复及用户小时/day 验收继续是待办，工业化
总目标保持 active。
