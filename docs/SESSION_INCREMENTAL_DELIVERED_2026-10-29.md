## 使用和回退

现有agent启动命令前加：

```bash
Q4T_SESSION_INCREMENTAL=1 ./build/q4t serve ...
```

仍须`--session-cache-dir DIR`与每请求原`session_id`；继续提交完整连续
历史，没有新的客户端字段。两种head、suffix和公共共享可按原配置组合。
完整可运行启动命令见[agent接入文档](AGENT_CACHE_INTEGRATION.md)。
`Q4T_SESSION_SAVE_TIMING=1`仅诊断时添加，默认不采分段计时。

功能回退：去掉环境变量或设`Q4T_SESSION_INCREMENTAL=0`并重启，恢复原
packed保存。进程重启会丢失现有匿名缓存；客户端完整历史允许重新prefill。
程序回退（先正常停止使用当前程序的服务，工具只接受封存的已知身份）：

```bash
python3 -B tools/evalscope/gpu_exclusive.py \
  --output .q4t-work/session-incremental-rollback-manual-01/lease -- \
  python3 -B tools/session_incremental/deliver.py rollback
```

每次回退使用尚未存在的独占锁输出目录。回退到6f3722…和原元数据5fdca8…；逐文件原子替换加恢复标记，不宣称两个
