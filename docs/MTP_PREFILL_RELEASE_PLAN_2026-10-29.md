## 身份、复用与测量范围

详细 SHA 绑定到执行前生成的 common/各阶段 plan。默认 build/q4t 在正式
接受前保持父版。复用上一轮零警告构建、两 head 独立 sliced GEMM 评分
与 pooled 状态合同、完整缓存跨槽恢复参考，以及同程序 200K 消融。
新旧 FP32/BF16 舍入差异和四代表目标层参考限制保持，不宣称任意输入
逐位等价。原 full 8K TTFT+0.202 秒/E2E+0.311 秒的负向记录永久保留。

复用未变的 suffix 索引/global ID/子集映射、32 短请求排队、SSD 格式、
租约/取消及监控 CPU 合同；受影响的 prefill、恢复后继续执行需新 HTTP。
旧身份性能不当成候选性能。单槽 max-seq=1 评分分派不变，既有单槽合同
复用；本次五档用实际受影响的四槽服务、请求并发1。普通 decode 单列重测。

全部 HTTP 用已有冻结材料：prefix-seed 的五档、11 条精确质量、开发缓存
生命周期材料、四个共享场景；suffix-agent 的长短重复代码/文本。不得根据
结果换题。开发生命周期和性能验收材料分离；这些是已知受控负载，不称
新业务泛化 holdout。完整 head 仍默认，子集独立显式选择。

## 总预算与顺序

从冻结执行计划起，绝对截止 **19800 秒（5.5 小时）**，含阶段间分析、
SSD 准备、发布及健康。最多 **302 生成 HTTP / 22 服务启动 / 0 新 GPU
fixture**；无重试、无备用扩样、无参数扫描、无新增 profile。健康只有
正式接受后使用。纯 CPU 方案/身份核对不是推理，离线分析不得改原始证据。

| 阶段 | 请求/服务 | 固定工作 |
|---|---:|---|
| A | 112 / 6 | full/subset/plain 父候选五档各3次=90；两候选各11条质量=22 |
| B | 24 / 2 | 两 head 各12条受影响缓存生命周期，含取消，不追加非法参数探测 |

每阶段完整驱动独占持有共享 GPU 锁，服务间不释放。A/B/S/C/H 依次执行，
每阶段结束核对 guard、postflight、最终监控屏障和自身进程清理后才能进入
下一阶段。阶段上限分别7200/1800/3600/12000/900秒，且都受总绝对截止
约束，不把各阶段上限相加后当成新预算。ENV_ABORT 立即停止，不自动重试。

首测为 tools/evalscope 真实 HTTP。A 顺序 full候选→full父版→subset父版

每档3次固定同输入。候选精确质量放在该服务五档之后，避免只给候选做
前置模型 warmup。实际首请求单列。MTP 服务开启 suffix 和两缓存池，但
五档/质量不带 session/scope，必须零快照读写。普通 decode 不启缓存。

诊断和旧评分环境开关均禁用。只计同配置当前父候选，旧计时单列。

S：full OFF→ON，subset ON→OFF，使用已有约131K主+32K/48K/近64K三子，

C：保持 suffix 和私有缓存；两臂公共池均启用，OFF 不发送共享字段，ON

full块0 OFF→ON、subset块0 ON→OFF、full块1 ON→OFF、subset块1 OFF→ON。
块0四场景顺序沿用原材料，块1反序；新服务空两缓存池，ID/scope隔离。
首次写入、共享恢复、私有保存和HTTP结束均计入事务净耗时。

8MiB中转，最多900秒且计入总截止，需100GiB可用SSD；保留至C结束后按
inode确认释放。它不是模型 warmup，不宣称SSD稳态，也不计入事务性能。

## 收益目标、保护项与决定

A 必须所有固定输出和质量正确；每head 200K三请求 TTFT 中位数各下降
至少20%，E2E中位数下降。15组五档的 TTFT、E2E、decode 全部公开，
各档不混算，所有负向原值保留。新旧接受分布逐项记录，不要求它证明
任意输入等价。ordinary decode、其他档位不允许已确认可归因性能退化。

S 每head/代码与文本四项都必须 E2E 净吞吐正收益（ON>OFF），同时输出/
容量/工作合同通过；decode单列。这里验证已交付 suffix 的净收益仍存在，
不重新要求旧未达标的子集decode≥3%，不追改原用户接受记录。

C 沿用原已交付目标：每head/场景两个配对块耗时比几何均值对应缩短，
8K≥3%、32K≥10%，且每块都正收益；八项目标分别满足，不能用完整head
替代子集或用32K抵消8K。完整输入/输出、共享命中、源0/子三次指定恢复、
主只写一份/子零写、长短槽、资源预算必须通过。第一块任何净收益≤0
即停止，不为了均值启动第二块。复用已有不变质量参考而非放宽门槛。

保护项逐项判断：合同/完整性失败，或独立机制/受控对照确认可归因退化
则 NO_GO；单个小差值不自动等于因果退化，也不自动算通过。原三次最低
重复及两个块属于有界描述性证据，不提供跨启动统计非劣。没有足够依据
则统计记未建立，工程决定按已授权目标、完整实测、直接合同、负值及
残余风险单列；不发明统一百分比容差，不走“纯删除冗余”豁免。

资源报告统一RAM的MemAvailable、进程RSS/VmSwap、预留账本、SSD共享/
私有写入与峰值，不能将host+device峰值相加。监控源不可用与采样边界
如实记录，不补零。保留CPU提交/等待/GPU区间上轮结论，不新增诊断扩样。

任何收益门槛未达、必要合同失败、监控/环境竞争或预算耗尽即停止，分别
记录证据有效性、测量完整性、统计结论、工程决定。失败保持6f37并归档，
不修候选重跑，不问一次性补跑例外。
