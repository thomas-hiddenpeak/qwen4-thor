# 48层采样的NVFP4/down独立参考

## 本轮结果

保持原接受运行时2392f6b1不变，将真实4K错题的快照扩展到全部
48层，每层预先固定为前两个活跃专家，共96个调用。不是全专家、
全MoE、全模型或decode验证。

- 实际4730240个FP4元素与独立重编码全部一致。
- 实际18920960个down输出BF16位模式与旧规则FP64参考舍入全同。
- 独立格式参考在295640组中发现707组高值提前饱和，分布于29层、
  35个采样调用；此次采样没有次正规不一致，不证明其他调用没有。
- 在每份输入保持原样的离线对照中，规范编码使2534个FP4码、
  1342031个BF16参考投影输出发生变化。35个受影响调用的局部
  激活重建L2误差全部下降，其余61个调用保持相同。

这些错误已经跨层出现；本样本没有发现实际FP4打包、checkpoint
down权重加载或down GEMM偏离旧规则参考的现象。但没有修正后的
跨层传播或整模型运行，不能把这些计数当作最终模型误差、质量
变化或“修正即可保持任务表现”的证据。此前失败候选继续拒绝。

## HTTP与采集边界

扩展观测库必要构建0、零警告后，首项测试为tools/evalscope真实
HTTP。原4K冻结输入无观测→有观测→无观测各一次，均600440，
4096输入/7输出、stop；三个服务0，质量驱动因原答案应360284均1。
MTP关闭、单流、greedy、max_prefill=8192、max_len=208896。
原错误保留，三侧相同不等于质量全通过。

层标记使用GatherQuant输入尺度缓冲区的首次出现顺序；每层限制
两个调用，总上限96。观察到48个不同标记，每个恰有两个不同专家。
随后逐份把实际GPU权重与反swizzle尺度同checkpoint对应层/专家
逐字节比较，96份全部匹配；实际input_scale和alpha也全部匹配。
因此层身份不是仅凭调用顺序推断。活跃专家不保证一定为0和1，
以每份实际metadata为准。

形状/矩阵描述符、同流复制、BF16/FP4/尺度/权重/输出读取约束沿用
[块与投影报告](E4M3_DOWN_REFERENCE_2026-09-23.md)。所有复制只读，
会加入同步开销，诊断时延不用于正式性能比较；本请求输出一致
不证明观测对其他请求均无影响。

HTTP及采集完整性核对完成后才分析快照。GPU重算程序与上一阶段
源码/接受版header相同，复用已构建二进制并保存摘要；没有链接
残留候选库。CPU侧独立枚举E4M3/E2M1、FP64矩阵参考及BF16位模式
核对全部保留。本轮允许记录GPU/FP64参考差异，不预设必须位同，
最终观测到全部位同；没有新增容忍阈值。

## 分布及限制

有格式不一致的采样层为：
0、1、2、3、5、6、11、12、14、15、16、17、18、19、21、22、23、
26、27、28、33、34、35、37、38、39、40、41、42。

最多的单调用包括第14层expert0的147组、第16层expert1的134组、
第18层expert0/1的77/65组。完整每层专家、行数、组数和差异计数
保存在multilayer-summary.json，不只报告最大值。

每个离线对照都固定该层原始SwiGLU输入，只替换本地尺度和重新
量化，再乘同一实际权重。修正后的输出没有送入下一层，因此
“1342031个变化”是独立局部反事实的总和，不是某个全模型修正
运行的实际变化数量。采样不是随机代表性样本，不能外推错误率。

当前验证了选中down支路的数值，不包括gate/up GEMM的完整独立
参考、全部路由专家、路由权重合成、共享专家、残差、attention、
GDN、PLE、最终logits或所有decode步。不能称为48层完整模型验证。
