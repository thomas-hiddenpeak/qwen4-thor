# 原生Realtime MCP：会话定义、执行与恢复

属于A01/A02/A10/A11/A12及R05/R06/Q01—Q03的后续实现。前一双向
音频阶段PR #55独立完成检查和合入；本计划不改变其已验发行。
总目标保持active，以下步骤是实现边界，不是删减功能范围。

## 已核对的协议与复用

2026-11-20核对[官方Realtime工具指南](https://developers.openai.com/api/docs/guides/realtime-mcp)
和固定OpenAI Node 7.47.0类型定义。session.tools和response.tools均
支持MCP；同一会话可通过server_label复用先前完整定义，新连接须
重新声明。工具目录实际导入后才可调用；审批经conversation item
返回，调用和生成分别有事件终态。工具结束不自动产生下一轮回答。

复用现有Responses的定义/目录/schema、部署权限、原生隔离transport、
持久审批与单次dispatch。原生模型继续由当前生成/配额所有者执行。
不新增外部守护服务；MCP端点失效只影响相应工具，健康LLM继续。
请求提供的MCP凭据只在当前连接私有状态中保留，不进入公开session、
模型提示、日志或证据。工具返回内容仍作为不可信外部内容处理。

## 实施与出口

1. **会话定义事务**：完整声明、label复用、按次覆盖、凭据替换与
   公开投影；定义数量/存储有界，失败更新不改变已确认状态，旧事务
   不覆盖新配置，连接之间不复用凭据。这里只准备定义，不伪造目录。
2. **真实目录与历史**：异步tools/list、进度/完成/失败事件，实际目录
   和私有调用授权绑定；只让已导入工具进入当轮模型输入。支持两种
   tools入口、持久Prompt和已完成MCP历史；来源/删除/迟到结果有所有者。
3. **调用与审批**：真实参数增量、原生执行、审批回填、结果事件及
   显式后续response；取消、超时、断连与执行结果未知不自动重放。
   工具失败、无可用工具、拒绝审批不伪造正常结果。
4. **实际闭环与恢复交付**：官方SDK、项目资料只读查询、直接调用与
   审批回填，检查当前客户用量、取消和资源清理；主轻/原生入口恢复/
   整包回退保留MCP能力，最后可回退发布与main合入。

完成后继续tracing、Live及全部master任务，不把拒绝合法请求当成
兼容完成。该模块当前尚未接入Realtime运行时。

## 本组冻结：定义事务

非性能开发。先成组实现，再必要host构建和18项针对性CPU：14项新
检查覆盖标签复用、连接隔离、显式目标/凭据替换、清除、重复定义、
无效更新、陈旧提交、删除后复用、数量/字节边界和公开投影；4项既有
Responses合同验证定义、私有凭据、目录与审批复用。0GPU/0HTTP；
默认rev396、runtime和已封包产物保持。来源文件及具体用例清单在
测试前冻结，失败只修复并重验受影响项，不扩展完整正确性或性能矩阵。
后续连接/执行组在准备完成时冻结相应CPU及必要GPU业务预算。

本组已完成[18项针对性CPU](evidence/serve-realtime-mcp-definitions-cpu-20261120/README.md)：
首次17通过/1失败，复用原生函数定义校验修复后重验受影响项通过，
未改17项复用。失败原件、源码及构建入口更正保留；runtime未连接，
默认rev396保持，继续步骤2—4。

## 本组冻结：真实目录与Realtime投影

新增原生目录导入适配和SDK目录投影，复用已有transport/部署权限/
加密私有目录。目录失败保持失败状态，通过独立事件报告；不能把
空工具列表一律当失败，也不能把导入处理完成当作已有可调用工具。
准备12项CPU：8项公开投影/边界、4项实际本机MCP HTTP夹具，合计
上限120秒；0模型启动/0LLM请求。具体冻结前将原拟重复的两项既有
合同替换为私有字段和远端schema反例，已有未改合同继续复用。
本机网络夹具是协议验证，不能代替模型驱动的真实资料查询验收。
之后接入异步会话所有者、调用和审批；公开运行时与默认仍保持。

本组[12项CPU已通过](evidence/serve-realtime-mcp-catalog-cpu-20261120/README.md)，
0.140秒，实际4项本机网络夹具。坏schema/远端失败只有失败目录，
凭据与私有会话不进入公开item；准入前取消/期限/权限和标识检查
保证无I/O。首次缺少类型include的构建失败保留，修复后零警告。
尚未接入公开运行时，继续异步会话及调用/审批，不宣称真实业务已验。

## 本组冻结：异步目录所有权与有界队列

实现会话线程拥有事件/历史、最多4个导入worker和64个保留条目，
保留私有目录16MiB及原历史16MiB分别有界；队列共用入队时的有限
期限。加载中的原生目录不阻塞普通文本；显式引用、其他工具待完成
状态仍按原合同。删除/替换只撤销该代目录，迟到结果不给调用授权，
取消/断连不启动排队任务，不自动重试导入或重放工具。

冻结20项CPU/120秒：14项异步工作/事件/错误/取消/期限/内存/所有者，
2项目录历史边界，4项直接受影响既有历史合同。0GPU/0LLM；原生
HTTP导入12项身份未变的证据复用。本组件完成后继续整体会话配置
事务和审批/调用接线，不能因有独立worker就宣称公开接口已接通。

本组[20项CPU通过](evidence/serve-realtime-mcp-imports-cpu-20261120/README.md)，
0.064秒；46.764秒host构建零警告。验证为异步所有权和直接受影响
历史合同，实际导入网络复用前组来源。继续公开会话事务和调用审批，
不将目录组件当完整MCP兼容；默认rev396 STOPPED保持。

## 本组冻结：MCP参数流与执行交接

生成终态与远端执行终态分离：从实际模型绑定投影MCP item与专用
参数delta/done，公开标签/工具名保持，模型别名不外泄。只有完整、
未取消/未删除且与有限最终消息一致的参数在response.done确认后
交接一次；历史仍pending，实际执行/审批终态由后续原生所有者负责。
不在参数完成时伪造远端成功，也不自动创建下一轮模型回答。

冻结20项CPU/120秒：12项MCP输出检查（含真实parser逐字节/多服务/
混合工具、截断/取消/失败、最终身份、删除、事件失败及单次交接），
8项直接受影响的既有函数和语音输出合同。必要host构建，0GPU/0模型；
当前默认rev396 STOPPED保持。接着串联会话配置/快照和原生审批执行，
再做模型业务与恢复交付，不以本组件通过结束整体任务。

本组[20项CPU完成](evidence/serve-realtime-mcp-output-cpu-20261120/README.md)，
累计33次执行/0.055秒。初始19通过/1失败，修正容量夹具后仍失败；
补充内部别名必须等于实际适配器映射的校验，12项MCP重验通过，
8项未改普通/语音分支复用。两次失败及错误初诊保留，3次构建零警告。
接着实现原生结果/审批回填、history审批身份成熟和整体会话接线；
公开运行时与默认保持，不将组件结果宣称为完整MCP闭环。
