# 后端监听地址合同

2026-09-27：本节点验收完成，已部署b5f38e48。

## 实现与兼容

`q4t serve`新增`--host`，默认`127.0.0.1`，只接受数值IPv4。
Start在读取tokenizer和分配模型资源之前验证地址与端口范围；Run
使用指定地址bind，日志记录地址，不在失败时退回所有网卡。

默认值从所有IPv4接口变为loopback，是有意的部署兼容变化：

```sh
# 同机代理的后端；显式配置便于审计，不依赖默认值。
./build/q4t serve --host 127.0.0.1 --max-seq 1 --max-prefill 8192 --max-len 208896
# 确实需要直接接受远程IPv4连接时，明确配置。
./build/q4t serve --host 0.0.0.0 --max-seq 1 --max-prefill 8192 --max-len 208896
```

也可以指定本机某个IPv4接口地址。`localhost`、IPv6、非法文本
不被接受；本轮没有新增DNS解析或IPv6双栈语义。地址不存在/端口占用
仍通过bind错误失败，不能静默切换地址或端口。

## 隔离边界

loopback阻止通过本机非loopback地址直接访问该监听socket，不是
租户身份鉴权或同机进程隔离。拥有同一网络命名空间访问权的进程
仍能直接连接后端，且仍受已知的128连接共享上限限制。容器代理
与Runner分属网络命名空间时，127.0.0.1不会跨容器连接，需要明确
的私有网络与访问策略；不能盲目改为0.0.0.0并宣称私有。

本次真实网络测试使用本机网卡地址连接并核对/proc socket归属，
不是另一台主机的端到端防火墙验收。未修改防火墙、TLS、认证，
未启用公网代理；上一阶段生成/控制入口预算仍按原范围解释。
