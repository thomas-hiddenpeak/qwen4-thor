# Serve 工业化持续目标与验收账

用户目标：**持续推进完善serve到工业水准**。这是持续目标，不以一个
子任务交付、兼容字段增加或单次HTTP通过作为完成。B1、05a/05b、
SRV-06/07/08/02b/01b均已限定交付；严格复制长输出的实际背压也已限定通过。
旧03b失败/预算保留，统一内存提前准入随后限定交付；同PID真实压力
恢复和64轮混合业务、本地运营告警/诊断/运行手册已限定接受。观测
端点饱和隔离也已限定交付；SRV-13旧ELF一小时通过，保留原停机分类
失败并定向修复，实际重启/回退/安装闭环已验。SRV-02e启动检查与
Thor计量随后限定交付；cudaMalloc实测揭示memcg缺口。SRV-02f文本/调度分配与释放失败传播已限定交付，原SSE取证失败保留。
下一步02g默认文本legacy加载与模型内部清理；完整物理保护仍未完成。

已确认范围：本机Thor、原生Qwen文本模型、OpenAI兼容Chat API、真实
项目资料/运行记录查询。部署边界已向用户询问；尚未答复时，开发规划
暂按单台Thor、多个受控内网客户端考虑，所有验证服务只监听loopback。
该暂定边界不授权公开网络部署。多模态、分布式和全部OpenAI端点不从
“工业化”推导为已有模型任务，但支持的接口必须形成完整可依赖合同。
