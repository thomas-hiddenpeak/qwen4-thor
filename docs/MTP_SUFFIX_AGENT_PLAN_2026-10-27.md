# 长短 agent 并发 suffix：实施与有界验收

用户于2026-10-27授权继续处理容量、prefill暂存和32请求排队，再验证两head
净收益。起点c1ad148；旧90f交付及c158研究归档保留，沿用codex/suffix-k3。
本阶段是容量/准入业务修复与suffix性能优化的混合任务，分别下结论。

## 实施边界

- 新显式`--seq-capacities 208896,65536,65536,65536`，配合max-seq4、
  max-len208896、固定max-prefill4096。显式列表必须完整合法且预算可容纳，
  不允许静默缩槽/截断。未指定列表保留旧等长布局。小于稀疏索引score
  window安全下限的极短显式槽在加载前拒绝，生产短槽65536不受影响。
- 大型KV/indexer按各槽实际容量分配，KV使用已有页表的全局物理页映射，
  indexer使用显式槽偏移；小型页表/RoPE仍按最大长度分配并完整计费。
  固定长度列表不是动态k或动态精度；不改变专家、PLE、head存储策略。
- 文本在槽位准入前完成分词，按输入+输出预算选择最小可用合适槽。
  4个执行槽与32个解析/排队/生成请求分开；保留48MiB全局HTTP body预算、
  单body16MiB、取消/超时/健康能力。不承诺任意32个16MiB请求均能排队。
- 显式容量布局下MTP逐prefill chunk消费trunk；非末块的shifted token已知，
  末块待target首token确定后处理。每请求仅保留一个chunk的trunk及rolling g。
  每次初始化一次draft状态，完整前缀最终与旧同chunk形状参考核对。
- suffix仍显式、greedy/k3、完整head默认，subset独立选择。min32/max64、
  4候选、完整三token与d0门保持。所有提交、取消、回退和槽位复用按请求隔离。

## 顺序、目标与预算

实现成组完成。必要构建不算测试；已知容量/准入缺陷可先做针对CPU合同，
不提前运行GPU微测。首模型测试为tools/evalscope真实HTTP；通过后直接GPU
状态参考和细分析。每GPU阶段完整驱动持有共享独占锁；沿用已修监控，
不新增Nsight，竞争/监控错误记ENV_ABORT，只清理自有进程。

先用真实workspace尺寸作一次CPU容量判定：唯一预定4096配置，不提高
mem-fraction、不扫描配置；不满足即模型加载前停止。本轮至多8构建轮/
3600秒、CPU合同600秒；最多2次GPU/验收具体失败修复，保留原错误，只验受影响项。

GPU总体上限18个服务启动尝试、323生成请求、4个局部GPU合同fixture、
首GPU启动后28800秒（8小时）；包含两次修复及健康额度，不重置绝对期限。
开跑前由机器清单冻结每次启动、请求、输入SHA、程序/依赖/环境身份。
全程自然继承页缓存，0额外warmup，不清缓存或改变功耗/亲和性。

预定矩阵：两head的suffix OFF/ON各两个反向配对块；每个启动包括重复
代码、重复文本、长短混合与非重复四组，每组1个131072输入主请求＋
三个32768/49152/短槽边界附近输入子请求（完整记录允许≤128token余量），共128请求。重复组目标输出
2048，输入材料预先保证短槽容纳输入+输出；对照组输出256。两head各自
报告完整请求组输出/makespan及decode，不能以命中率或full收益代替subset。
最低值得投入目标：每种head两重复场景配对几何平均E2E净收益≥1%、
decode≥3%，两块收益方向及所有原值公开。若首块收益无净正值或正确性/
容量/排队失败，不继续条件第二块。目标是有界工程评估，不声称统计非劣。

正常15启动（首HTTP独立1、长短对照8、单流保护6），健康1、具体失败
修复2；正常320请求、健康3。首11HTTP后关服务，再执行3个局部GPU
fixture（第四个保留为受影响修复额度）；两head各7组mixed状态参考及
streamed初始化，以及完整attention布局。8个生命周期请求含两head各
3个取消/复用及1个输出尾部请求。

另有22精确质量请求（含五档长质量）、16+32突发共48请求、8个取消/复用
请求。单流保护比较90f与候选：full/subset suffix ON及plain，各五档3次
共90请求；两head单流代码/文本各3次/身份共24请求。部署健康最多3请求。
总128+22+48+8+90+24+3=323。未受影响证据复用要记录依赖，不能复用旧
计时替代新增调用路径的同配置对照；未执行项不记通过。

目标/草稿直接参考覆盖不等长槽、全/部分/零接受、混合神经行、非零单槽、
短槽末端、EOS、取消及复用。增加完整attention的布局对照，不能仅靠双GDN
target参考证明KV/indexer寻址。streamed draft init按同chunk边界比较完整
有效KV、next_d0/g；不以不同M的逐位差异当成合法性依据或放宽容差。

保护项：实际四槽与长输入不截断、32突发服务完成、HTTP/SSE/质量、状态
合同、普通decode、各档TTFT/decode、混合/非重复、统一RAM。明确的缺陷或
可归因回退不能用重复收益抵消。按源身份分别复用旧索引、全局ID/子集映射、
短数字及监控合同。记录索引init/增长/释放、匹配、接受、实际batch/verify/
extend工作量；不编造未采集的独立GPU耗时。

证据有效性、测量完整性、统计结论、工程决定分别记录。预算不足/无收益/
合同失败则归档候选并保持90f交付；不追加样本直到通过。具备条件则按既有
授权完成回退包、适用程序/发布元数据、有界健康检查、文档及提交推送。
