# E4M3 缺陷修复交付包

包含可独立复现的格式修复补丁和回归，不修改默认运行时。
完整修复是此前归档的实现：高区间有限编码、次正规最近偶数舍入
及进位。本轮33146条非负有限格式输入，CPU/GPU与独立定义和
CUDA原生转换对照：原版147项失败，完整修复0项失败。
这不覆盖全部FP32、NaN/Inf/负数，也不是模型任务质量证明。

## 独立复现

在原版header SHA256为24c37223...的检出中执行：

```bash
python3 tools/verify/e4m3_site_http/reproduce_format.py \
  --output .q4t-work/e4m3-repro-new
```

脚本只在新的输出目录复制header、应用full-format-fix.patch、
零警告编译并核对原版失败/修复通过；无需模型或旧归档文件。
已有输出目录拒绝覆盖。完整SHA记录在脚本中，来源不同则停止。
原版checker退出1始终是发现缺陷，不写成原版通过。

run.py --site input/inter是2026-09-27有期限实验控制器，依赖当天
prepared计划和备份，不是通用重复实验入口。对全MoE层prefill和

源码修改期间不要运行其他生产构建或编辑同一文件。
